# 우리 둘의 이야기 v6.7 — 연연(緣硏) 브랜드 테스트

- 분석 시스템 브랜드: 연연(緣硏). 서비스 이름은 우리 둘의 이야기.
- 분석 시작 시 3단계 로딩 애니메이션(최소 약 2초) 표시. 실제 서버 분석 결과를 기다립니다.
- 본문 강조 서식을 절제하고 소개 문구를 수정했습니다.
- 정신건강의학과 전문의 검토 문구를 추가했습니다. 실제 전문가 검토 사실과 일치하는지 출시 전에 확인하세요.
- 커플 카드 PNG 2종 모두 오른쪽 아래에 작은 연연 인장을 직접 포함했습니다. 다운로드 파일에도 인장이 남습니다.
- 무료 미리보기 → 흐릿한 유료 예고 → 테스트 결제 버튼 클릭 시 실제 청구 없이 전체 리포트 표시.
- 사주만 사용하며 MBTI·별자리는 분석하지 않습니다.
- GitHub 저장소 루트에 압축 해제한 파일과 assets 폴더를 함께 업로드하세요. Render는 render.yaml 사용.
