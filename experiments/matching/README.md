# 운영과 분리한 매칭 비교

루트에서 `python -X utf8 experiments/matching/extended.py` 실행. 설치 의존성은 서비스와 같다. 운영 matcher를 import해 기준 결과를 읽고, 대안 순위는 이 폴더의 함수에서만 계산한다. 웹 서버는 이 실험을 import하지 않는다. 12,000쌍 보정(seed 20261001), 독립 평가 4개 seed × 2,400쌍. 표본은 양력 1970~2004년, 매월 1~28일 및 정시 출생으로 한정되므로 실제 이용자 분포를 대표하지 않는다.

|방법|등장 유형|최대 점유율|기존 결과 유지|
|---|---:|---:|---:|
|기존|8|33.04%|2400/2400|
|A 백분위 거리|11|19.88%|956/2400|
|B 백분위 방향|12|21.50%|621/2400|
|C 평균·표준편차 보정|8|32.88%|1362/2400|
|D 기준점 투영|11|24.46%|978/2400|
|E 보정+투영|11|18.58%|976/2400|

기존 미출현: c10/f01/f02/f04. B는 독립 3개 seed에서도 12종이 나오지만 기준 평가에서 f04는 3/2400(0.125%)에 불과하다. B의 기존 결과 유지율은 25.9%이며 c06 보호 입력 6건 전부 c18로 바뀐다. A/C도 보호 6건 전부가 바뀌고 D/E는 4건이 바뀐다. D/E에서는 f01과 f03의 투영 기준점이 같아 ID 동점 처리로 f03이 사라진다. 분포만으로 어느 안도 운영 후보로 확정할 수 없다.

6개 방법 모두 9,600쌍 순위 반복 및 입력 교환 일치. 기준 seed의 방법별 전체 리포트 반복 2,400/2,400, 5장 구조 누락 0. 거리 손실은 기존 기준에서 얼마나 멀어졌는지에 관한 대리지표이며 의미 정확도가 아니다. 정답 라벨과 사용자 적합도 검토가 없으며 대안 순위와 기존 설명 함수의 해석도 함께 재설계해야 한다.

원자료: extended-results.json. 실행 전후 사주·매칭 보호 파일 SHA-256 불변을 assert하고 결과에 기록한다. 운영 변경·병합·배포는 하지 않는다. 사용자 비교 후에도 서사별 적합성 검토 없이는 자동 적용하지 않는다.
