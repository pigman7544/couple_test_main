# 연연 궁합 엔진 v1.3

v1.2와 동일한 출생 정보 딕셔너리를 `compatibility_v13.analyze_pair(a, b)`에 전달하면 명식, 근거, 원국 및 교차 가설의 선정 기록과 한국어 3장 원고를 반환한다. `compatibility_v13.report_markdown(result)`로 원고를 출력한다. 웹 서비스 연결은 별도 작업이다.

## 근거 해석

- 원국에서는 월지 본기, 지장간 층위, 투간, 통근, 지장간의 위치를 함께 점수화한다. 지장간을 순위화하고 다른 십성이 나타나는 차순위 근거를 남긴다. 월주나 시주가 미확정이면 확정된 주로 가설을 제한한다.
- 교차에서는 일·월주에 더 큰 편집 비중을 두고, 각 원국의 핵심 지장간·투간과 같은 자리인지, 상대가 그 글자를 읽은 십성이 양방향 일간 십성과 겹치는지 반영한다. 합과 충·형·해가 함께 나타나면 먼저 주가 겹치는 후보를 확인한다. 상충은 검토할 대안 가설이며 실제 관계를 관찰한 결과가 아니다.
- 월지 본기를 대표 근거로 사용하며 절입 후 일수에 따른 사령은 별도로 계산하지 않는다. 같은 천간을 우선하고, 음양이 다른 동오행은 보조 통근 후보로 취급한다. 형의 두 글자 및 세 글자 조합은 v1.1의 규칙을 따른다. 합화, 격국, 용신, 길흉은 판정하지 않는다. 순위 가중치는 명리 학파의 통일 기준이 아닌 편집 가정이다.
- 가설을 연결하는 구조는 명식에 따라 달라지며, 본문 표현은 규칙 기반 한국어 문장과 상황 소재로 구성된다. 이용자의 실제 성격과 경험은 입력에 없으므로 상황을 가정으로 제시한다.

## 24쌍의 비교

`python evaluate_compatibility_v13.py v13-review`

1970년부터 2010년 범위에서 생성한 합성 입력 24쌍. 48명 중 12명은 출생시간 미상이다. 명식과 교차 근거가 24쌍 모두 동일하다.

| 자동 지표 | v1.2 | v1.3 |
| --- | ---: | ---: |
| 원고 본문 글자 수 합 | 19,916 | 30,242 |
| 근거 없는 문단 | 0 | 0 |
| 연결 대상이 없는 근거 ID | 0 | 0 |
| 교차 상충 근거를 포함한 리포트 | 23 | 23 |
| 서로 다른 마무리 문단 | 20 | 20 |
| 한 편 안에서 반복한 문장 검출 건수 | 0 | 13 |

구체성은 개인별 근거에서 행동을 도출하고 두 십성이 같은 경우를 별도로 읽도록 확장했다. 개별성은 마무리 문단의 완전 일치만 기준으로 보면 개선이 없다. 명리 정합성은 기존 계산과의 동일성 및 참조 연결을 검사했다. 문장력은 독립 채점 전이며, 상용 원고를 판단하기에는 반복 문장과 문단 호흡이 남은 과제다. 본문 분량은 품질 점수가 아니다.

## 독립 판독 자료

`blind-review.md`에는 표본별로 명식과 순서를 섞은 A/B 원고가 들어 있다. 명리와 한국어 원고를 검토할 독자는 버전표 `key.json`을 열기 전에 각 원고를 아래 기준으로 1–5점으로 기록하고 대표 문장을 근거로 남긴다.

- 구체성 — 행동과 맥락을 구별할 수 있는가?
- 개별성 — 다른 표본에 이름만 바꿔 붙여도 성립하는 서술이 얼마나 적은가?
- 명리 정합성 — 원국과 교차 해석의 방향·위치가 맞고 상충과 불확실성을 보존하는가?
- 문장력 — 한국어 흐름·호흡이 자연스럽고 전문용어·반복이 읽기를 방해하지 않는가?

점수 1은 기준을 거의 충족하지 못함, 3은 부분 충족, 5는 일관되게 충족을 뜻한다. 각 기준의 쌍별 차이와 승·무·패를 버전 공개 후 집계한다. 출력 형식 차이로 버전을 추측할 수 있으므로 준블라인드 자료다. 독립 독자 또는 명리 전문가가 완료한 채점은 아직 없다.
