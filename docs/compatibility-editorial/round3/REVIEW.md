# 연연 궁합 리포트 3차 검토

**판매 기준 미달 · 배포 보류.** 기존 계산을 사용하여 새 출생 입력으로도 3장 초안과 문단별 근거를 생성한다. 독자용 문장은 2차 수작업의 변별력과 기준 원고의 인과 설명에 미치지 못했다.

## 산출물과 재현

[기존 20쌍 전문](matched.md) · [홀드아웃 24쌍 전문](holdout.md) · [기존 쌍 근거 색인](matched-audit.json) · [홀드아웃 근거 색인](holdout-audit.json) · [반복 지표](metrics.json) · [고정 입력 규칙](holdout.json)

저장소 루트에서 `python evaluate_compatibility_editorial_round3.py`를 실행한다. 운영 v1.4와 같은 정규화 출생 딕셔너리를 `compatibility_editorial_round3.analyze_pair(a, b)`에 전달하는 방식이다. 24쌍은 합성 양력 입력으로, 첫 생성 전에 시드·날짜 범위·절입 인접 및 윤일 앵커·시각 누락 정책을 고정했다. 두 시각 모두 있는 쌍 6개, 하나만 없는 쌍 12개, 모두 없는 쌍 6개를 포함한다. 모든 표본을 유지했다. 제품의 음력·윤달 입력 변환 경로는 이번 후보를 통해 시험하지 않았다.

## 생성과 검증

1. v1.2 사실 추출에서 기존 명식, 월지 본기, 투간, 방향별 십성, 교차 조합과 미확정 위치를 가져온다.
2. 기존 편집용 순위에서 개인의 중심·대안 역할, 교차 방향, 합과 긴장, 공유 자리, 같은 글자를 두 일간으로 읽은 관점을 취한다. 짝이 없는 경우 확보된 조합과 방향별 근거로 범위를 좁힌다.
3. 8개 생활 장면에 공통 역할 적합도를 적용한다. 동률이면 선언 순서를 따른다. 출생 값이나 표본 번호를 장면에 대입하지 않는다. 2차의 20개 장면 파일은 생성기가 읽지 않는다.
4. 1장에서 각자 무엇을 중요하게 여길지, 2장에서 함께하려는 이유와 한 선택이 갈리는 순간을 제시한다. 3장은 같은 선택에 개입할 행동, 각자의 관찰 질문, 의견 차이가 남았을 때 살필 실제 부담을 붙인다. 장면은 가정이다.
5. 문단별 근거가 계산 결과에 존재하는지, 미확정 기둥을 인용했는지 검사한다. 색인의 ID는 해당 입력을 다시 실행한 결과의 근거 사전에서 찾을 수 있다. 행동을 권하는 문단의 ID는 가설의 출처이며 효능에 대한 증거는 아니다.

## 문장과 내용 판정

자체 비블라인드 검토다. 문장 1/2, 개별성 1/2, 근거 연결 1/2, 서사 1/2, 실천 1/2로 본다. 1은 해당 구조가 구현됐으나 판매 기준의 자연스러움이나 설명력을 갖추지 못했다는 뜻이다. 아래는 집계에 잡히지 않는 대표 실패다.

| 표본 | 문장·서사·근거 | 실천 |
| --- | --- | --- |
| 기존 01·15 | 같은 장보기와 대체품 대화에 묶인다. 01의 시간 미상과 15의 별개 위치 합·충이 각 장면의 인과를 다르게 만들지 못했다. | 대체품 한도라는 질문은 실행 가능하다. 두 쌍의 실제 부담을 가를 정도로 달라지지는 않는다. |
| 기존 04·19 | 둘 다 예약과 육해다. 04의 같은 기둥 합·해와 19의 분리된 삼합·육해를 사실 문단에서 구별하지만, 행동에서 그 차이를 충분히 설명하지 못했다. | 취소 조건 확인은 비용을 드러내나, 대리 결정이나 회신 참여 여부를 따로 검증하지 못한다. |
| 기존 11 | 같은 식신을 두 사람 모두의 도움 의사로 읽는다. 삼형의 연쇄 조건을 2차 식사·설거지처럼 눈앞의 연쇄로 전개하지 못한다. | 정리 범위를 확인할 수 있으나 조정 뒤 생기는 두 번째 부담을 실제 장면에서 제시하지 못한다. |
| 홀드아웃 01 | 수납을 돕는 쪽과 자기 물건을 함께 정하고 싶은 쪽의 이유가 같은 행동에서 만난다. 계산에서 생활 해석으로 넘어갈 때 여전히 안내 문장에 의존한다. | 손대기 전에 묻고 동의 범위를 비교하는 실천이 같은 행동에 붙는다. |
| 홀드아웃 04·20 | 자형에서 되풀이 확인을 묻지만 예시 속에서 확인이 돌아오는 과정 자체가 나타나지 않는다. | 한 가지 조건을 바꾸는 제안과 반복 확인이 줄었는지 묻는 질문의 연결이 약하다. |
| 홀드아웃 09 | 긴장이 선택되지 않아 기본 질문을 쓴다. 장면에서 어느 말 때문에 두 사람의 반응이 달라지는지 흐릿하다. | 조정 전후 비교가 가능하지만 먼저 떠올린 갈등을 뒷받침할 조합은 선택되지 않았다. |
| 홀드아웃 13·18 | 같은 역할 두 개를 설명할 때 중복을 줄였지만 두 사람의 다른 이유를 충분히 드러내지 못한다. | 두 사람에게 같은 변수가 중요한 경우, 개별 부담을 알려 주는 두 번째 질문이 더 필요하다. |

기존 조사·호응 정규식으로 잡힌 문장은 0개다. 대화에서 질문 뒤에 또 질문으로 응답하는 식의 기계적인 접속, 한자와 근거 설명의 밀도, 필요의 명사화는 별도 편집이 필요하다. 문단 근거 누락·미해결 ID는 0개다. ID 검사는 근거와 문장의 존재 관계를 확인하며 해석의 타당성, 문법 전체, 구매 가치에 점수를 매기지 않는다.

## 판매용 기준 원고 5편 대조

| 기준 표본 | 3차와 비교한 판매 기준 |
| --- | --- |
| 01 | 기준은 조용히 쉬면서 다시 연결되는 두 가지 방법을 대등하게 준다. 장보기로 생성된 3차에서는 각자의 자유와 이유 설명이라는 단서가 한 장면에서 충분히 이어지지 않는다. |
| 02 | 기준과 2차는 시험 제작과 주문·확정 사이의 책임 이동을 보여 준다. 3차 대체품 장면은 동의 범위와 선택권을 확인하지만 분량과 참여 비용이 커지는 과정을 담지 못한다. |
| 03 | 기준은 같이 쓰고 싶은 이유와 반복 정리 비용을 함께 유지하면서 두 번 비교한다. 3차는 예약 전 취소 조건을 한 번 묻기 때문에 계속할 수 있는 분담인지 살피기 어렵다. |
| 04 | 기준은 공동 결정과 공동 답장에 자기 표현이 포함되는 경험을 구분한다. 3차 예약 장면에서는 어떤 표현이 대리 결정처럼 들렸는지와 각자 답하는 선택지가 희미하다. |
| 05 | 기준은 둘이 계속할 의사와 다른 사람을 초대할 의사를 별도로 확인한다. 3차 장보기는 대체품 선택은 구체적이나 활동의 공개 범위에 견줄 두 단계 결정이 부족하다. |

## 테스트와 다음 작업

- 3차, 2차, 1차, v1.4, v6.7 관련 테스트 18개 통과. 기존 미리보기와 언락이 v1.4를 사용하는지 확인했다. 승인 UI, RS·IL1·미리보기1·카드 관련 코드와 배포 설정은 변경하지 않았다. 브라우저와 실서버를 재검증하지 않았다.
- 같은 로컬 소스와 Python 3.11 환경에서 전체 테스트는 2차 96개, 3차 99개였다. 양쪽 실패 15개, 오류 66개이며 각 테스트 이름의 차집합은 비어 있다. 기존 소켓 권한 및 Git 이력 의존 오류, 기존 원고·강조 실패가 포함된다.
- 다음 편집에서는 역할에 맞는 일반 대사를 삽입하는 방식을 줄이고, 같은 구체 선택에 두 사람이 각각 어떤 비용을 치르는지부터 구성해야 한다. 긴장 유형별로 사건의 전개와 시도할 행동이 함께 달라져야 한다. 상형·예약과 같은 편중을 보완한 뒤 새 고정 표본에서 블라인드 비교, 명리 감수, 독자 평가를 수행한다.
