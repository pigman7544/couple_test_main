# 연연 궁합 리포트 2차 편집 검토

**판매 기준 미달 · 배포 보류.** 1차와 동등한 20쌍에서 장면과 실천을 연결하는 데 성공했다. 다만 계산 문단과 관계 가설 사이의 설명, 대안 해석의 깊이, 독립 감수를 기준 원고 수준으로 확보하지 못했다.

- 전문은 [2차 원고 20편](round2.md), [1차 원고](../after.md), [v1.4 원고](../before.md)에서 확인할 수 있다.
- [2차 문장 목록](round2-sentences.json)의 ID는 표본·장·문단·문장이다. [1차 목록](../after-sentences.json)과 [v1.4 목록](../before-sentences.json)의 ID도 같은 형식이다. [문장 비교](sentence-comparison.jsonl)의 각 행은 비교 방향, 출발 문장 ID, 같은 쌍·장 안에서 가장 가까운 도착 ID, 유사도 순이다. 일치 단서가 없으면 도착 ID는 null이다. 네 방향을 기록하므로 사라진 문장과 새 문장을 모두 찾을 수 있다. 이 대응은 어휘 기반이며 편집상 같은 뜻이라는 판정과는 구분한다.
- [쌍별 수치](metrics.json)의 글자 수는 공백 포함 본문 기준이고 순서는 v1.4, 1차, 2차다. 로컬의 `trace.json`은 기존 [근거 사전·해석 계획](../pairs.json)에 연결된다. 2차에서만 사용한 근거 카드는 각 쌍의 new_evidence에 있다. 마지막 장의 ID는 시험의 효능을 입증하는 자료가 아니라 질문을 세운 출처다.

## 집필 구조

1장은 각자의 일간과 십성, 월령을 읽는 월지 본기, 확인된 투간과 위치를 제시하고 둘이 같은 장면에 들어갈 이유를 세운다. 2장은 방향별 교차 십성과 합·충·형·해의 층 및 공유 자리를 설명한 다음, 두 사람이 같은 말에 동의했다가 무엇에서 갈릴 수 있는지 한 장면으로 보여 준다. 3장은 그 장면에 나온 조건 하나를 바꿔 보고 양쪽의 응답이 달라졌는지, 그대로라면 어떤 가설을 다시 봐야 하는지 적는다.

기존 계산과 근거 선택을 이용했다. 월령의 사령·강약·격국·용신은 추가 판정 범위 밖이다. 02의 巳申 상형은 기존 조합표에서 채택한 해석이며 삼형 완성을 뜻하지 않는다. 하나의 지지 본기를 두 일간에서 읽은 십성은 장면을 해석하는 단서이며 각자의 실제 행동이나 사건을 추정하는 자료가 아니다. 아래의 상반 근거는 각 상황의 가능성을 좁히는 해석이다. 교차 합이 선택되지 않은 01에서는 양쪽 일간의 겁재를 공통 관심의 단서로 읽었다.

장면·가설·시험은 이 20쌍에 대해 직접 집필했다. 기존 입력과 1차의 근거 계획이 일치할 때만 검토 원고를 만든다. 새 입력에 적용되는 장면 선택이나 원고 생성의 일반화는 검증 범위 밖이다. 이 선택으로 같은 틀에 역할별 문장만 바꿔 넣을 때 생기는 문제를 분리해 검토할 수 있다.

## 반복과 유사 표현

| 지표 | v1.4 | 1차 | 2차 |

| 본문 문장 | 468 | 522 | 384 |

같은 문장의 재등장은 1차 49.2%에서 2차 10.7%로 줄었다. 문장 부호와 공백을 제거한 뒤의 완전 중복 수도 세 버전에서 각각 동일했다. 근접치는 정규화 문자의 3글자 묶음 집합으로 Jaccard 유사도 0.60 이상인 위치를 한 번씩 센다. 완전히 같은 3글자 집합은 제외한다. 앞선 다른 쌍만 비교하므로 순서의 영향을 받으며, 쌍별 부분 집합에서는 이 지표가 항상 0이다. 수치는 우회 표현과 의미 중복을 놓칠 수 있다.

1차의 최다 반복인 확인 문장(15회)은 사라졌다. 2차에서는 ‘시주 정보가 미확정이라 확인된 위치까지만 읽었습니다’가 9회로 가장 많다. 비슷한 문형은 계산 문단에 집중되며, 06·12·17은 어휘가 달라도 모두 좋은 의도가 상대의 재량을 줄이는 육해의 서사를 쓴다. 02·08·10 역시 처음 동의한 범위를 다시 가르는 같은 편집 논리를 공유한다. 3장에서도 부담이 남으면 다른 요인을 찾는 구조는 반복한다. 따라서 중복률과 개별성은 따로 채점했다.

## 20쌍 자체 편집 평가

순서는 **문법·문장 / 서사 / 개별성 / 실천**이다. 0은 누락·불명료, 1은 읽을 수 있으나 추론 또는 구체성이 부족함, 2는 해당 항목이 본문에서 성립함을 뜻한다. 실천 2는 작게 바꿀 행동과 관찰, 가설이 맞지 않을 때 다르게 읽을 단서가 있는 경우다. 1차의 6항목 점수와 직접 합산하지 않았다. 이 평가는 작성자의 비블라인드 검토이며 독립 명리 감수·편집·구매자 평가는 확보하지 못했다.

기준은 두 사람의 또 다른 선택이 왜 가능한지 충분히 보여 주고, 일반 사실과 가상의 대화를 같은 문단 안에서 이어 읽게 한다. 2차의 압축은 기존 공통 문장을 걷어 내는 데에는 도움이 되었지만 이런 이중 관점을 함께 압축했다. 따라서 20편 모두 판매 수준 도달 판정을 보류한다.

## 재현과 범위

저장소 루트에서 `python evaluate_compatibility_editorial_round2.py`로 산출물을 다시 만들고 `python -m unittest test_compatibility_editorial_round2 test_compatibility_editorial test_compatibility_v14 test_v67`로 관련 검사를 실행한다. 로컬에서는 저장소 인접 작업본에 보관된 Python 3.11과 달력·천문 라이브러리를 사용했다. Windows 기본 Python 진입점과 앱 번들 Python에서 각각 실행 및 외부 모듈 로딩 오류가 있었으며, 이 오류를 제품 코드 수정 없이 우회했다.

관련 테스트 15개 통과. 1차 코드와 2차 후보를 포함한 전체 발견 테스트는 각각 94개, 96개였으며 양쪽에 실패 15개와 오류 66개가 있었다. 이전 작업 보고서의 실패 20개·오류 59개와 이번 로컬 실행은 환경과 결과가 다르다. 실패·오류 테스트 이름 목록은 두 실행에서 일치했다. 오류 중 59개는 Windows 소켓 권한 오류(10013)였고 Git 이력에 의존하는 스냅샷도 로컬 소스 사본에서 읽을 수 없었다. 기존 문학형 원고와 강조 검증의 실패 역시 재현됐다.

Draft PR은 1차 검토 브랜치를 기준으로 한다. 온라인 미리보기·언락 경로와 승인 UI, RS·IL1·미리보기1·카드 자산은 PR 변경 범위에서 제외했다. v1.4의 관련 테스트는 실행했고 실제 브라우저 및 Render 화면의 미리보기·카드는 재검증 범위에 포함되지 않았다. 판매 판단에는 별도 편집 및 명리 감수, 독자 평가와 표본 외 검토가 남아 있다.


GitHub 자동 검토가 상세 출생 입력과 파생 명식 정보를 담은 trace.json의 업로드를 차단했다. 이 파일은 작업공간에만 남겼다. 이 문서의 표에는 20쌍의 근거·해석 연결을 기록했다.
