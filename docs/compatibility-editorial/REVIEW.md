## 문장과 문단 검토

문장 번호는 표본·장·문단·문장의 순서다. 본문 468개 및 522개 문장 위치에 반복 횟수와 감수 표식을 붙였다. 같은 문장을 한 번만 세는 통계와 실제 독자가 만나는 출현 횟수를 함께 볼 수 있다. 표식은 발견한 대표 표현을 재현하는 규칙이다. 표식이 없는 문장도 뜻이나 근거 연결이 약할 수 있다. 조사·호응과 의미 문제는 한 문장에 동시에 생길 수 있다. 근거 설명력과 개별성은 문장 번호에 연결된 문단과 쌍 전체에서 함께 판단했다.

## 생성과 검증

- 해석 계획은 기존 사실 사전에서 주·대안 십성, 월지 본기, 투간, 같은 글자의 반복, 확정 범위, 교차 작용 위치와 층, 같은 글자의 양쪽 십성을 고른다. 사주 계산과 v1.4의 랭킹 규칙은 재사용했다. 월령·통근 가중 해석을 새로 만들지 않았다.
- 한국어 집필은 계획을 받아 각자의 읽기, 두 관점이 만나는 장면, 그 가설을 확인할 행동을 작성한다. 합·충·형·해의 배치에 따라 설명을 바꾸고, 한 사례에 필요한 근거만 문단에 붙인다. 실제 사건·역할·결말은 가정하지 않는다.
- 재생성은 저장소 루트에서 python evaluate_compatibility_editorial.py, 기준만 생성하려면 --baseline-only를 사용한다. 회귀 검증은 python -m unittest test_compatibility_editorial test_compatibility_v14 test_v67 이다.
- 관련 테스트 13개 통과. 출생 입력부터 재계산해 결정성, 명식과 근거의 동일성, 같은 글자의 관점, 5개 배치, 기존 대표 문장 결함, 공개 미리보기·언락의 v1.4 출력 일치를 검증했다. 전체 탐색은 같은 로컬 소스에서 기존 테스트만 89개, 새 테스트 포함 94개를 각각 실행했다. 양쪽의 실패 목록이 일치했다(실패 20, 오류 59). 오류에는 Windows 소켓 제한(10013)이 있었고 실패에는 기존 문학형 원고와 역사 스냅샷 검증이 포함된다. 브라우저와 실제 배포 환경의 화면·카드는 재실행하지 않았다.
- 남은 편집 한계는 서사의 연결이다. 역할별 어휘와 예시가 명식마다 다르게 조합돼도, 장면의 어느 행동이 합에서 형·충·해로 넘어가는지 이어지는 문단이 적다. 표본 외 독립 감수와 기준 미달 항목의 개선 없이 출시할 근거가 없다. 원국 위치를 생활 사건에 고정으로 대응시키지 않는 범위에서 장면의 구체성과 가설 검증력을 함께 높여야 한다.
