# 작품별 해설 확장

PR #13 위에 쌓는 원고 교정이다. 나머지 10종에 각 작품의 중심 장면에서 읽어 낸 독립 해설을 추가했다. 새 사건이나 인물의 내면을 사실로 단정하지 않고 제목과 본문에서 문학적 해설임을 밝혔다. c01/c06 원전 본문은 그대로다.

예: 견우직녀는 재회 전의 생활과 기다림 부담, 온달·평강은 성취 이전의 가치와 응원의 한계, 오만과 편견은 이해와 책임의 구분, 개츠비·데이지는 기억과 현재의 선택권을 다룬다. 우정 작품은 원작의 동행을 해석하고 실제 사용자 관계를 단정하지 않는다.

같은 출생 차트 기준 전체 5장 분량의 c06 대비 비율: c01 96.8%, c02 95.8%, c03 96.1%, c10 95.9%, c11 95.8%, c13 94.2%, c18 95.0%, f01 98.5%, f02 98.8%, f03 98.8%, f04 99.2%. 공백·마크업을 포함한 문자 수이며 실제 독서 만족도의 측정값이 아니다. 시간 미입력을 포함한 3쌍으로 12종 모두 90~120% 범위도 검사한다.

전체 Python 검사 30개 통과. 처음 실행에서 과대 요청 오류 검사 한 건이 로컬 연결 중단(WinError 10053)으로 실패했으며 동일 검사 전체 재실행에서 통과했다. 기존 Node 화면 대역 검사는 main에서 바뀐 제목 '어떤 이야기를 남겼을까?' 대신 옛 제목 '어떤 사랑을 했을까?'를 기대해 실패한다. 이번 원고로 UI는 바뀌지 않았으며 이 오래된 기대값은 후속 QA 변경에서 정리한다.

문학적 동등 품질은 자동 테스트로 확정할 수 없어 편집 검토 대기 상태다. 원전 신규 사실·인용을 추가하지 않았으며 독립 원전 대조 완료를 주장하지 않는다. 병합·배포하지 않는다.
