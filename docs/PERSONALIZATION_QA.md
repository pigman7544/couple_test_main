# 리포트 개인화 1차

기준: main 9a8e43d. 12종의 기존 5장 구조에 일간의 오행, 각자의 필요를 나타내는 기존 해석, 모든 공동 최다 오행을 반영한 현실 해설과 실천 질문을 추가했다. 갈등·표현·자율성의 기존 점수 구간으로 가상 대화 장면을 고른다. 임의 난수나 생일 해시로 문장을 바꾸지 않는다. 같은 명리 특징을 가진 입력은 같은 해석일 수 있으며 무한한 고유 소설을 보장하지 않는다.

원전 장은 변경하지 않았다. 화면·인트로·PNG·미리보기·계산·매칭·언락 정책은 변경하지 않았다. 테스트의 보호 파일 비교만 Windows 줄바꿈을 정규화했다. 이 검사는 PNG 바이트를 그대로 비교한다.

검증: 기존 26개 테스트 통과(로컬 HTTP 포함). 추가 3개 검사: 12종 모두 관계 점수를 고정해도 출생 차트가 바뀌면 해설·조언 변경, 원전 불변, 입력 불변, 순서 교환 시 새 개인화 문단의 인물별 내용 추적, 무료 응답 불변. 2,400쌍 전체 응답 반복 2,400/2,400, 순서 교환 시 매칭 2,400/2,400. 역할 동점은 기존 입력 순서 정책을 유지하므로 교환 전후 전체 리포트 바이트 동일성을 요구하지 않는다. 결과 JSON은 qa-personalization.json.

운영 매칭 재현: c01 793, c02 477, c03 108, c06 703, c11 267, c13 2, c18 1, f03 49. c10/f01/f02/f04 미출현. 최대 점유율 33.04%. 이 문제는 해결됐다고 표시하지 않는다.

현재 첫 변경만으로 나머지 10종의 분량은 c06의 약 79~84%다. 후속 교정에서 작품별 독립 해설을 확장한다. 분량은 품질의 대리지표이며 문학적 완성도 승인으로 취급하지 않는다. 실제 배포·브라우저 시각 검수는 수행하지 않았다.
