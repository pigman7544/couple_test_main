# 연연 궁합 엔진 v1.2

## 실행

Python 3.11과 기존 `requirements.txt`를 사용합니다.

```python
from compatibility_v12 import analyze_pair, report_markdown

result = analyze_pair(
    {"year": 1992, "month": 3, "day": 18, "hour": 16},
    {"year": 1992, "month": 4, "day": 30},
)
print(report_markdown(result))
```

`charts`는 v1.1의 확정 명식과 절입 전후 후보입니다. `contexts`에는 월지와 계절, 월지 본기와 일간의 생·동일 오행 관계, 지장간 층위·십성·투간 위치, 천간별 통근 후보가 들어 있습니다. `interactions`와 `evidence`에는 합·충·형·해의 참여자, 위치, 원문 기호, 당사자와 상대 일간에서 본 십성이 연결됩니다. `plan`은 개인별 주목 근거, 대표 교차작용과 다른 방향의 근거, 두 방향의 일간 십성, 대화 장면을 선택합니다. `report`는 세 장의 문단에 근거 ID를 담고, `review`는 누락·미해결 ID, 문장 중복, 번역투 표현 목록을 검사합니다.

이 모듈은 독립 호출로 실행합니다. PR의 v1.2 변경은 분석·평가·테스트·설계 문서 추가입니다.

## 역법과 해석 가정

- [v1.1 역법](COMPATIBILITY_V11.md)의 절기 구분, 고정 UTC+9, 자정 일진 교체, 분 단위 입력을 그대로 사용합니다. 월령은 확정된 절기 월지와 그 본기를 뜻합니다. 진·술·축·미도 각 계절에 속하고 월지 대표 오행은 토입니다. 절입 후 며칠째인지에 따른 사령 분할, 진태양시, 역사적 시간대, 야자시 일진 교체는 계산 범위 밖입니다.
- 지장간 구성은 v1.1과 같고 층위를 따로 지정합니다. 본기 중심으로 읽되 자·묘·유는 본기 한 글자, 오·해는 본기와 중기 두 글자를 사용합니다. 이 표는 절입 후 사령 일수표와 별개이며 본기·중기·여기의 명칭과 배분은 학파에 따라 달라질 수 있습니다.

  | 지지 | 본기 | 중기 | 여기 |

  | 子 | 癸 | — | — |
  | 丑 | 己 | 辛 | 癸 |
  | 寅 | 甲 | 丙 | 戊 |
  | 卯 | 乙 | — | — |
  | 辰 | 戊 | 癸 | 乙 |
  | 巳 | 丙 | 庚 | 戊 |
  | 午 | 丁 | 己 | — |
  | 未 | 己 | 乙 | 丁 |
  | 申 | 庚 | 壬 | 戊 |
  | 酉 | 辛 | — | — |
  | 戌 | 戊 | 丁 | 辛 |
  | 亥 | 壬 | 甲 | — |

- 좁은 통근은 확정 지장간에서 천간과 같은 글자를 찾습니다. 같은 오행의 반대 음양은 별도 후보로 기록합니다. 투간은 같은 원국의 확정 천간에서 같은 글자가 보이는 모든 위치입니다. 시주 또는 연·월주가 미확정이면 알려진 범위 안에서만 서술합니다.
- 교차작용은 v1.1의 조합 규칙을 재사용합니다. 모든 참여 위치를 남기고 지지의 교차 십성은 본기로 읽습니다. 삼합·삼형은 세 글자가 모일 때, 각 상형은 v1.1에서 정한 두 글자가 모일 때 기록합니다. 한 쌍의 위치에 여러 작용이 겹칠 수 있습니다. 합화, 반합, 형의 방향·성립 조건, 용신·격국·신강약 판정은 계산 범위 밖입니다.
- 일주·월주·시주·연주의 4·3·2·1은 편집 우선순위입니다. 대표 교차작용을 고를 때 참여 위치의 평균을 쓰고, 반대 방향 근거는 같은 위치·층위를 공유하면 먼저 읽습니다. 대화 장면은 대표 작용이 일주 외 기둥에 닿을 경우 그 자리에서 고릅니다. 위치별 생활 주제와 십성별 질문은 관계를 돌아보기 위한 편집 가정입니다.

## 무작위 20쌍 비교

```sh
python -m unittest -v test_compatibility_v12 test_compatibility_v11 test_v67
python evaluate_compatibility_v12.py --samples review.md
```

시드 `20261121`로 1900~2049년 양력 생일 40건을 생성했습니다. 출생시각 미입력은 10건입니다. 같은 입력으로 v1.1과 v1.2를 대조했습니다.

| 검사 | 결과 |
| --- | --- |
| v1.1과 확정 명식 및 후보 일치 | 20/20쌍 |
| v1.1에서 서로 다른 관계 주제 배열 | 12/20쌍 |
| v1.2에서 서로 다른 해석 배열 | 20/20쌍 |
| 서로 다른 실천 문단 | 20/20쌍 |
| 대표 조합과 반대 방향 근거를 함께 설명 | 18/20쌍 |
| 근거 없는 문단, 미해결 ID, 문서 내 동일 문장, 등록 번역투 문구 | 각각 0건 |

v1.2의 배열에는 대표 작용의 종류·위치, 반대 근거의 종류, 두 방향의 십성, 실천 장면이 포함됩니다. v1.1에는 자연어 리포트가 없어 주제 배열과 해석 배열의 차이를 비교했습니다. 두 지표는 해석 설계가 달라지는 정도를 보여 주며 관계의 적중률이나 블라인드 문장 품질 점수로 쓰지 않습니다.

표본 1·2는 일지 상형이 같아도 반대 근거가 천간합과 육합으로 갈리고, 두 사람의 정재·정관 방향이 바뀌어 실천 질문도 달라졌습니다. 표본 13은 두 사람의 일지와 월지에 걸친 삼합을 삼형과 함께 보존했습니다. 문단 전체가 달라도 같은 장면의 첫 질문은 여러 번 나옵니다. 20쌍 가운데 월주 장면이 13쌍으로 가장 많았습니다. 기술용어 밀도와 문장의 자연스러움은 독립 독자 평가가 필요합니다.

## 생성 샘플

아래는 시드 표본 1의 생성 결과입니다. 두 사람의 생일은 평가용으로 생성했습니다.

## 1장. 각자의 명식에서 읽히는 것

첫째 사람의 월지는 여름에 속하는 미(未)이며, 본기 기(己)의 오행은 토입니다. 첫째 사람의 일간도 월지 본기와 같은 토에 속합니다. 첫째 사람의 일간과 같은 무(戊) 글자는 일주 지지 술(戌)에도 본기로 들어 있습니다. 첫째 사람의 월주에 든 기(己) 글자를 일간에서 보면 겁재이므로 ‘누가 먼저 결정을 내릴지’라는 주제로 읽어 볼 수 있습니다.

둘째 사람의 월지는 가을에 속하는 신(申)이며, 본기 경(庚)의 오행은 금입니다. 둘째 사람의 일간은 월지 본기에서 생을 받는 오행에 속합니다. 둘째 사람의 확정된 지지에서는 일간과 같은 계(癸) 글자를 찾을 수 없습니다. 둘째 사람의 월주에 든 경(庚) 글자를 일간에서 보면 정인이므로 ‘어떤 도움을 받으면 마음이 놓이는지’라는 주제로 읽어 볼 수 있습니다.

둘째 사람의 출생 시각을 몰라 해당 시주는 해석에서 뺐습니다.

## 2장. 두 사람의 명식이 만나는 자리

첫째 사람 일주 술(戌)·둘째 사람 일주 미(未)에서 상형 조합이 나타납니다. 떠올려 볼 장면은 ‘같은 일을 두고 서로의 기준을 자꾸 확인하게 되는 순간’입니다.

첫째 사람 일주 무(戊)·둘째 사람 일주 계(癸)에는 천간합도 있습니다. 여기서 살필 대목은 ‘말을 꺼냈을 때 상대가 그 뜻을 이어받는 장면’입니다.

첫째 사람에게 둘째의 일간은 정재, 둘째 사람에게 첫째의 일간은 정관입니다. 대화에서 첫째가 살펴볼 주제는 ‘시간이나 돈을 꾸준히 나누어 쓰는 법’, 둘째가 살펴볼 주제는 ‘서로 지키고 싶은 약속’입니다.

## 3장. 일상에서 나눠 볼 이야기

둘이 쉬는 방식이 다를 때, “오늘은 같이 쉬고 싶어, 각자 쉬고 싶어?” 하고 물어보세요. 이어서 “이번에 서로 시간이나 돈을 얼마나 쓰면 편할까?”라고 물어도 좋습니다. 각자 당연하다고 여긴 기준을 하나씩 말해 보세요. 먼저 들은 사람이 그 기준을 짧게 되짚어 줘도 좋습니다.
