# 관계 구조 종합 분석

이 단계는 검증된 계산 원장과 집필 사이에 놓이는 수동 편집 명세다. C의 입력은 각 표본의 기존 근거 원장이다. [결정 기록과 C 문단 연결](decisions.json)에서 핵심·보조·반대·범위·미선택 근거를 추적한다. 각 배열은 우선순위 점수가 아니며, 항목은 여러 역할을 가질 수 있다. 문단 번호는 C 본문 위에서부터 1–5이며 공통 안내문을 제외한다.

1. 확정 자리와 미확정 범위를 먼저 기록한다. 후보만 있는 월주를 취사선택하지 않는다.
2. 배우자성은 양방향 상대 일간 십성을 기록한 뒤 재성·관성 계열과의 접점을 별도로 표시한다. 입력에는 전통의 성별 배정에 필요한 정보가 없으므로 해당 배정은 보류한다. 비겁은 교차 십성이다. 배우자궁은 각자의 일지이며, 일지 내부 십성과 상대 일간 십성을 별도로 적는다.
3. 월지 본기와 겉으로 드러난 글자의 출처를 적는다. 월지 본기의 투간, 일지 본기와 월간의 일치, 자료 범위로 판정할 수 없는 경우를 구별한다. 투간은 강약이나 사건 발생을 확정하지 않는다.
4. 교차 작용을 사람·기둥·천간/지지별로 묶는다. 같은 자리·층에 걸린 상충과 같은 일주의 서로 다른 층에 걸린 상충을 구별한다. 일지–일지 이외의 작용은 실제 위치를 유지한다. ID가 제한된 원장에서는 다른 작용의 부재를 결론 내리지 않는다.
5. 핵심 논지 하나를 제안하고 이를 제한하는 반대 읽기를 함께 기록한다. 보조 근거나 다른 후보를 뺀 이유를 남긴다. 글에서는 계산·전통 해석·가상 장면을 구별하고, 실제 역할을 특정하지 않는다. 근거가 희박하면 논지를 좁히거나 보류한다.
6. 문단별 ID를 대조한다. 파생된 생활 제안은 가설로 표시한다. 서로 다른 자리를 한 자리로 합치거나 재성·관성의 방향을 바꾸면 수정한다.

## 01 · 선택권의 대칭, 충이 걸린 자리의 비대칭

- **배우자성 양방향**. 丁→丙 겁재, 丙→丁 겁재. 상대 일간의 재성·관성 접점은 이 두 ID에서 나오지 않는다. 배우자궁 내부에는 첫째 巳의 丙 본기 겁재·庚 중기 정재, 둘째 戌의 辛 여기 정재가 있다. 양쪽에서 정재가 읽혀도 층위가 다르다. 둘째의 일지 본기는 이 편집 원장에서 미선택 범위다.
- **월지**. 첫째 월주는 己酉/庚戌 후보이고 시주 미확정이다. 둘째 卯의 乙 본기는 정인이다. 월간 辛인 사실은 명식표로 확인한다. 둘째의 본기는 월간과 다르며 다른 기둥 전체에 걸친 투간 판단은 원고에서 보류했다.
- **중심과 반대 읽기**. 첫째 일지 巳와 둘째 시지 亥의 육충을 개인 계획과 함께 비워 둔 시간의 경계에 적용한다. 서로 겁재라는 대칭은 자율성의 문턱을 양쪽에 열어 준다. 두 일지의 정재는 지속 가능한 공동 약속도 별도로 살피게 하므로 자율성 일변도의 읽기를 제한한다. 첫째 월·시가 비어 있어 관계 전반으로 넓히지 않는다.
- **미선택**. 둘째 亥의 본기 壬 편관은 충의 대상을 식별하는 보조 사실이다. 시지 하나에서 부담의 주체를 특정하는 비약을 줄이기 위해 C에서 십성 해석을 덜었다.

## 02 · 같은 두 배우자궁의 합과 형

- **배우자성 양방향**. 丙→辛 정재(재성), 辛→丙 정관(관성). 첫째 배우자궁 申 본기 庚 편재와 둘째 배우자궁 巳 본기 丙 정관은 각자 기준이다. 첫째의 교차 정재와 일지 편재를 동일한 십성으로 읽지 않는다.
- **월지**. 양쪽 午 본기 丁은 각각 겁재와 편관이다. 첫째 월간 庚은 일지 본기 庚과 같고 월지 본기 丁과 다르다. 둘째 월간 戊 또한 월지 본기 丁과 다르다. 이 둘은 월지 본기의 월간 투간으로 해석하지 않았다. 양쪽 기둥 확정 범위는 coverage ID로 확인했다.
- **중심과 반대 읽기**. 같은 일지 申·巳의 육합과 상형을 한 묶음으로 보존했다. 합은 협업이 시작되는 실마리이고 형은 같은 일을 이어갈 때 기준을 다시 볼 실마리다. 합은 마찰 일변도의 읽기를, 형은 순조로움 일변도의 읽기를 제한한다. 두 글자의 상형은 채택 규칙에 따르며 합화·우세·길흉은 보류한다.
- **미선택**. 巳의 戊 여기 정인은 맥락을 받아들이는 별도 후보지만, 이번 논지는 도움의 기간과 책임을 따라간다. C는 반복 약속에 집중했다.

## 04 · 두 일주의 위아래에서 달라지는 연결

- **배우자성 양방향**. 甲→己 정재, 己→甲 정관. 첫째 배우자궁 申 본기 庚은 편관, 둘째 배우자궁 亥 본기 壬은 정재다. 교차 일간과 배우자궁 내부의 방향을 따로 읽는다.
- **월지**. 첫째 월지 戌 본기 戊는 편재이고 월간 庚은 일지 본기와 일치한다. 둘째 월지 申 본기 庚은 상관이고 월간에도 그대로 드러난다. 두 庚의 출처와 십성이 다르다.
- **중심과 반대 읽기**. 두 일간 甲·己의 천간합과 두 일지 申·亥의 육해를 각각 위아래 층에 둔다. 합은 실행 조건이 갈린다고 목표까지 다르다고 볼 이유를 줄이고, 해는 목표 합의가 곧 세부 합의라는 읽기를 제한한다. 戊 편재는 첫째를 압박만 느끼는 사람으로 고정하는 읽기를 제한한다. 둘째 시주가 미확정이라 장기 계획까지 넓히지 않는다.
- **미선택**. 첫째 coverage는 확정 범위를 대조하는 데 쓰고 원고 설명에서는 덜었다. 戊 편재는 계산 문장과 반대 읽기에 유지했고, 별도 장면의 주제로 확장하지 않았다.

## 고정 검증 표본 03 · 문서 절차 적용

이전 비교에서 빠진 번호 중 첫 번째인 03을 명식 확인 전에 선택했다. 기존 24쌍의 3번째 합성 입력은 양력 1975-01-16 07시 / 1979-04-08 03시다. 이 표본은 이전 A/B 비교에서 미사용이었다. 별도 평가 데이터에서 완전히 격리된 표본이라는 이력은 확보하지 않았다.

- 첫째 甲寅·丁丑·壬戌·甲辰, 둘째 己未·戊辰·乙巳·戊寅. 교차는 壬→乙 상관, 乙→壬 정인. 재성·관성의 상대 일간 접점은 성립하지 않는다. 배우자궁 본기는 戌의 戊 편관과 巳의 丙 상관이다. 월지 본기는 첫째 丑의 己 정관(월간 丁), 둘째 辰의 戊 정재(월간에서도 戊)다. 두 coverage 모두 확정이다.
- 두 일지가 직접 만나는 작용은 현재 계산 원장의 해당 위치에서 검출되지 않았다. 중심 후보는 첫째 일지 戌–둘째 월지 辰 충이다. 같은 戊가 각각 편관과 정재로 읽힌다. 생활 적용을 한다면 일상에서 맞추는 기준과 반복되는 일정의 조건을 구체적으로 확인하는 정도다.
- 반대 읽기와 한계는 둘째 일지 巳도 첫째 연지 寅과 형·해를 이루므로 마찰을 한쪽 자리의 현상으로 고정할 수 없다는 점이다. 첫째 일지–둘째 연지 상형과 첫째 월지·일지–둘째 연지 삼형은 구별해 기록하되 같은 戌이 걸리는 중첩을 독립 증거처럼 더하지 않았다. 이 사례의 수동 우선순위는 일지–월지를 연지가 포함된 후보보다 앞에 둔 편집 선택이다. 다른 순서로 읽을 수 있다.
- 검증 ID는 `pair.a.reads.b`, `pair.b.reads.a`, `a.day.hidden.戊`, `b.day.hidden.丙`, `a.month.hidden.己`, `b.month.hidden.戊`, `a.month.stem`, `b.month.stem`, `pair.육충.a.day.b.month`, `pair.상형.a.year.b.day`, `pair.육해.a.year.b.day`, `pair.상형.a.day.b.year`, `pair.삼형.a.month.a.day.b.year`, `a.coverage`, `b.coverage`다. 테스트는 원장의 계산과 위치 및 이 범위의 참조를 확인한다. 평가용 C를 추가 작성하지 않았으므로 원고 품질 일반화는 미검증이다.
