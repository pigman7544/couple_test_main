## 춘향 기토 · 이몽룡 신금 재현

양력 1982-09-13, 시간 미입력과 양력 1981-06-02 03:00을 사용했다. 공개판 Chapter 1은 배역 설명 뒤에 일간의 비유, 월주 상투 문장, 오행 설명 및 독립적인 생활 조언을 정해진 순서로 붙였다. 춘향의 옥중 선택에는 기토의 생활 돌봄을 뒷받침할 행동이 나오지 않는다. 이몽룡이 돌아온 대목과 신금의 세심한 품격도 문장 안에서 이어지지 않았다. 목소리가 다른 문단이 모인 이유는 작품·일간·월주·상황의 선택이 별도 규칙에 있었고 연결을 확인하는 조건이 없었기 때문이다.

공개판의 실제 표현 일부다.

> 당신을 상징하는 사주 글자, 일간은 기토(己土)이에요. 무언가를 길러 내는 부드러운 밭을 떠올려 보세요. 가까운 사이에서는 서로의 생활을 보살피는 리듬을 바라는 모습에 비춰 볼 수 있어요. 이를테면 “노력을 알아봐 주는 인정” 같은 배려를 받는 날, 함께하는 시간이 한결 편안할 수 있겠죠.
> 태어난 달의 글자를 함께 읽으면 또 다른 표현 방식도 떠올라요. 함께 계획을 짤 때 각자의 의견을 동등하게 놓고 싶을 수 있어요. 앞의 비유와 꼭 같은 모습일 필요는 없어요. 먼저 챙겨 주고 싶은 날에도, 내 마음을 들어 주길 바라는 날이 있으니까요.
> 태어난 달의 글자를 함께 읽으면 또 다른 표현 방식도 떠올라요. 좋아하는 간식을 챙기듯 작은 행동을 꾸준히 이어 가는 모습도 떠올라요. 앞의 비유와 꼭 같은 모습일 필요는 없어요. 먼저 챙겨 주고 싶은 날에도, 내 마음을 들어 주길 바라는 날이 있으니까요.

## 전체 장 편집 검증

- 무료 미리보기의 발췌를 실제 관계 장에서 가져오고 모든 커플에 붙던 일반 예고 문구를 걷었다. 첫 화면은 출생정보의 역할을 간단히 밝히고 1장은 작품 속 행동과 근거가 있는 해석에 집중한다. 관계 장에 끌림·안정감·성장 고정 칸을 두지 않았다.
- 12종 모두 작품 속 사건 → 각자가 다르게 이해할 수 있는 상황 → 말할 수 있는 문장 또는 선택을 확인했다. 견우·직녀는 다시 만나는 날짜가 전승에서 주어진 조건이므로 무토의 꾸준함 대응을 양쪽 다 해제했다. 온달·평강은 필요한 정보를 주는 일과 신청을 대신 결정하는 일을 나눴다. 로미오·줄리엣은 함께하고 싶은 뜻과 비용·시점을 나눠 듣도록 했다. 오디세우스·페넬로페와 개츠비·데이지는 각각 바뀐 생활 조건과 과거 활동을 되풀이해야 한다는 기대를 다룬다. 우정 4종은 단서와 보이지 않는 수고, 추진과 안전 조건, 사정과 책임, 이견과 공동 목표를 각각 다룬다. [한국학중앙연구원 견우직녀 설화](https://encykorea.aks.ac.kr/Article/E0002170)
- 검토본은 24명의 28개 장면을 사용한다. 인물과 일간의 240개 조합 중 **48개**에서 인물의 행동과 연결된 일간 해석을 사용하고, **192개**에서는 인물의 행동과 독자 경험에 관한 질문을 사용한다. 견우·직녀는 작품 근거와 연락 경험을 중심으로 읽는다. 자동 검사는 근거의 사용 여부와 후속 문장을 확인한다. 판본별 세부 묘사 및 한국어의 설득력은 독립 감수와 독자 검증이 남아 있다.
- 가상 장면은 유형별 상황을 설명하기 위한 편집 예시다. 사용자 실화처럼 다루지 않는다. 표본에서 30자 이상 문단의 리포트 내 완전 중복은 0건이었다. 유사한 조언을 다르게 말하는 의미 중복까지 수치로 검증한 결과는 아니다. 줄거리와 일부 조언은 같은 유형에서 공유된다.

## 재현 방법과 검증 범위

```shell
python -m pip install -r requirements.txt
python -m unittest test_v67 test_report_paths test_latest_matching test_report_evidence test_c06_report test_c11_report.C11ReportTests.test_plain_language_and_contextual_questions
python tests/audit_a1.py --source ../yeonyeon-evidence-preview --output a1-results/before.json
python tests/audit_a1.py --source . --baseline a1-results/before.json --output a1-results/after.json
python -m unittest discover
```

- 241개 가상 입력에 시간 입력·누락, 양력·음력, 15분 단위 시각을 포함했다. 6개 유형이 자연 선택됐다. 추가 통제 12건에서 각 유형의 전 장을 생성했다. 전체 1,200개 유형·일간 조합으로 근거가 있는 해석의 사용과 보류, 무료/언락 연결, 관계 장 산문을 검사했다.
- 전후 241개 입력의 선택 유형·명식·카드 링크와 계산·매칭 관련 파일 4개의 SHA-256이 같았다. 기존 135건 검증에서는 무료·언락의 전체 후보 순서와 점수도 확인했다.
- 로컬 카드 24개는 모두 실제 PNG이며 이미지 묶음을 확인했다. Edge 모바일 390px에서 앱 58개 장, 서가 111개 장, 첫 이미지와 마지막 다운로드 24건을 확인했다. 내려받은 파일은 원본과 동일했다. 화면 검사에서 8종은 자연 입력으로, 표본에서 1위가 나오지 않은 4종은 테스트 서버에서 유형을 지정해 열었다. 이번 A1의 서가 검증은 표시 및 장 이동 중심이다.
- 공개 Render의 동일한 24개 카드 경로를 GET으로 확인하니 백소정·허선 2개는 HTTP 200, 나머지 22개는 404였다. 새 검토본의 자산은 공개 Render에서 제공되지 않는 상태다.
- 기본·HTTP·매칭·편집 회귀 26개가 통과했다. 전체 검사는 A1에서 75개 중 57개 통과, 18개 실패였으며 이전 Work의 74개 중 19개 실패와 비교했다. 남은 18개는 기준 소스에서도 실패했다. 이전 해석 문구, 월주·전체 명식에 따른 장별 변화, 강조량 기대값 외에도 실제 분량 격차 검사가 남아 있다. 양쪽 로그와 브라우저 결과는 `a1-results` 폴더에 있다.
