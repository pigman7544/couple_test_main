# 연연 궁합 엔진 v1.1

Python 3.11과 기존 `requirements.txt`로 실행합니다. 현재 서비스는 기존 계산·매칭·리포트 경로를 사용합니다.

```python
import json
from compatibility_v11 import analyze_pair

result = analyze_pair(
    {"year": 1992, "month": 3, "day": 18, "hour": 16},
    {"year": 1992, "month": 4, "day": 30},
)
print(json.dumps(result, ensure_ascii=False, indent=2))
```

- 입력은 정수 `year`, `month`, `day`와 선택 `hour`, `minute`, `calendar` (기본값 `"solar"`, 음력 `"lunar"`), `leap` (윤달 여부)입니다.
- `charts`는 입춘과 12절의 태양 황경으로 정한 연주·월주, 민간력 날짜의 일주, 두 시간 단위 시주를 담습니다. 출생시각이 빠지면 시주는 비워 두고, 절입으로 연주나 월주가 갈리는 경우 가능한 연주·월주 조합을 함께 반환합니다. 확정된 주만 분석에 사용합니다.
- `details`는 천간 십성과 지장간별 십성을 제공합니다. 오행 개수는 확정된 천간과 지지의 대표 오행을 각각 한 번씩 셉니다. 지장간 가중치나 신강·신약 판단은 포함하지 않습니다.
- `relations`에는 원국 내부 및 두 원국 사이 천간합, 육합·삼합, 육충, 상형·삼형·자형, 육해가 참여 위치와 함께 기록됩니다. 삼합·삼형에는 세 지지가 모두 필요합니다. 이 버전은 합화와 학파별 추가 규칙을 계산하지 않습니다.
- `evidence_cards`는 개인 또는 두 사람 범위와 주제별로 사실을 모아 중복 서술을 줄입니다. 각 카드는 원자료 위치, 전통적 의미, 가능한 강점·긴장, 생활 적용과 해석의 한계를 담습니다. 중요도는 근거 유형과 위치(일주, 월주, 시주, 연주), 반복 횟수로 정한 편집 가설입니다.
- `selection`은 개인별 최대 두 주제, 관계 최대 세 주제와 주요 주제를 반환합니다. 관계에 합과 충·형·해가 함께 있으면 양쪽 카드가 남습니다. 중요도와 주제 선택은 보고서 편집을 위한 것으로, 관계를 측정하거나 예측하는 값이 아닙니다.

기존 역법의 고정 UTC+9와 자정 일진 교체를 적용합니다. 역사적 시간대·일광절약시간·출생지별 진태양시와 23시 일진 교체는 계산 범위 밖입니다. 달력 지원 범위는 기존 Korean Lunar Calendar 패키지에 따릅니다. 입력은 분 단위이며 공개 달력에 반올림된 절입 시각과 분 경계에서 판정이 다를 수 있습니다.

절입 검사는 [한국천문연구원 2024년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2024)의 12절 시각 전후 2분을 비교합니다. 일진은 같은 자료의 2024-02-10 갑진일을 기준으로 별도 날짜 차이 계산과 대조합니다. 무작위 검증은 시드 20261120으로 1900~2049년 양력 생일 200개를 생성해 100쌍을 구성합니다. 음력과 윤달은 고정 사례로 따로 검사합니다.
