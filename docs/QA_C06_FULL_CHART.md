작업 기준: 개발 브랜치 `feat/selective-body-emphasis`, 시작 원격 커밋 `388179fc89b42e5124819943489975994805f2ea`. 운영 main과 운영 서비스는 수정하지 않는다.

## 구현 범위와 한계

- 기존 사주 기둥 계산·관계 6축·매칭·배역 기준·무료 미리보기 응답·카드 파일 보존.
- `c06_chart.py`가 월령의 중심 지장간, 일지 중심 지장간, 시주 겉글자 십성을 주요 위치로 읽고 다른 겉글자와 전체 지장간을 함께 사용한다. 중심 주제의 편집 가중치는 월령3, 일지2, 시주2, 일간 외 겉글자1, 지장간 각0.25다. 동점은 고정된 주제 순서로 결정한다. **명리학의 정통 강약 산식이나 과학적 예측 모델이 아니다.**
- 지장간은 고정 본기 우선 표다. 절입 후 며칠째인지에 따른 사령 분할은 구현하지 않는다. 계절은 절기로 계산된 월지에 대응한다.
- 통근은 지장간에 일간과 같은 오행이 있는 위치 목록이다. 뿌리의 깊이·득령·투간을 종합한 신강약 판단은 하지 않는다. 뿌리 유무는 현실 장면을 고르는 보조 비유에만 쓴다.
- 명식 내부 위치 쌍의 육합/육충, 두 사람의 모든 4×4 위치 간 육합/육충/천간합을 계산한다. 합화·삼합·형해파·용신·대운은 이번 범위에 포함하지 않는다. 시각 미입력은 시주·시주 관련 비교를 제외한다.
- 5개 주제별 끌림·갈등·가상 장면·실천·질문을 연결하고, 일지·시주·통근·합충의 보조 문장을 더한다. 같은 입력은 같은 출력이다. 같은 특징 묶음에서는 일부 문장이 같을 수 있으며 모든 명식에 고유한 창작문을 보장하지 않는다.
- 특정 癸×丙 조합에서 전체 리포트를 고정 원고로 덮어쓰던 서버 경로를 해제했다. 고정 디자인의 병화·계수 소개와 그림도 전체 명식 리포트의 안내에서는 제외한다.
- 2장 전승 본문은 기존 `TALE`을 유지하고 개인화 질문을 분리한다. 널리 알려진 판본 차이·심리 해석의 한계를 표시한다. 이번 작업에서 특정 원전 판본 전체와 신규 대조한 것은 아니다.

## 실제 입력으로 찾은 비교 표본

모두 양력·한국 시간, 사용자가 제공한 개인정보가 아닌 테스트용 가상 입력이다. 유형을 강제하지 않고 기존 `rank()`의 1위가 c06인지 확인했다. 상대방은 고정하여 첫 번째 사람의 기둥 변화 효과를 비교한다.
