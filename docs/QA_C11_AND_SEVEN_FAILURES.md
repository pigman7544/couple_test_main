## 2. c11의 실제 A/B

두 입력 모두 유형을 강제하지 않고 실제 `compute → relation → rank` 경로에서 c11이 선택된다. [입력](../tests/fixtures/c11_comparison.json), [응답·명식 근거 비교](qa-c11-comparison.json).

| | A | B |
| --- | --- | --- |
| 당신 | 1999-01-22 01:00, 갑술일 | 1996-12-13 21:00, 갑신일 |
| 상대방 | 1998-11-09 21:00, 경신일 | 1986-10-21 09:00, 무술일 |
| 당신의 중심 주제 | 미리 챙기는 배려 | 생각할 시간 |
| 상대방의 중심 주제 | 말과 경험의 나눔 | 각자의 선택 |
| 4장 → 5장 | 먼저 예약한 식당에 대한 서운함 → 예약 전에 물어보고 함께 다시 고르기 | 생각 중인 답을 거절로 받아들임 → 다시 연락할 때를 말하고 설명 듣기 |
| 원고 분량(5장 합산) | 1,817 → 4,115자 | 1,813 → 4,129자 |

- 1장은 실제 기존 배역 기준을 유지하며 인물별 소제목 두 개만 쓴다. A는 엘리자베스/다아시, B는 다아시/엘리자베스 순서다. 성별을 배역 근거로 사용하지 않는다.
- 일간의 자연 상징을 먼저 설명하고 월령·일지·시주와 전체 겉글자·지장간에서 선택한 관계 주제를 생활 언어로 잇는다. 내부 `chart_evidence`에 십성·통근·합충을 남긴다. c06의 추출 규칙을 그대로 재사용하며 계산·매칭의 가중치를 바꾸지 않는다.
- 두 샘플의 당신은 모두 갑목이지만 월령·일지·시주 등이 달라 다른 갈등과 선택으로 이어진다. 별도 검사에서는 일간과 관계 점수를 고정하고 월주·시주만 바꿔 1·3·4·5장이 달라지는지 확인했다. 이 검사는 날짜로 계산한 샘플과 구분되는 합성 명식 민감도 검사다.
- 2장의 원작 사건과 문학적 해설은 A/B 공통이다. 4장은 가상 장면으로 표시하며 실제 경험으로 단정하지 않는다. 5장은 같은 장면의 다음 대화를 제안한다.
- [A 변경 전](review-c11-A-before.md) · [A 변경 후](review-c11-A.md) · [B 변경 전](review-c11-B-before.md) · [B 변경 후](review-c11-B.md).
- 무료 예고·표어와 응답의 유형·이미지 유무·테스트 모드는 변경 전후 동일했다. c06 A/B의 실제 응답은 기존 fixture와 완전 일치했다.

원작 근거는 Jane Austen의 [Pride and Prejudice 원문](https://www.gutenberg.org/cache/epub/1342/pg1342-images.html), 3장(무도회), 34~36장(첫 청혼·편지·자기 판단 재검토), 43장(펨벌리), 52장(리디아의 일), 58장(다시 전하는 마음)이다. 사건 요약과 문학적 해설을 구분했고 기존 한국어 번역을 인용하지 않았다. 원문에서 확인한 행동을 사주로 예측한 사실처럼 쓰지 않았다.

## 3. 검증과 한계

- 실제 Chrome, c11 A/B × 360·390·1440px × 다섯 장 = **30개 장** 검증. API와 DOM 본문 일치, 두 소제목, 실제 볼드 굵기·문단당 최대 2곳, 점수 비노출, 가로 넘침·화면 오류 없음. 각 크기 A/B 일반 입력 → 무료 미리보기 → 테스트 언락 6회도 통과했다. [로컬 결과](qa-c11-local.json).
