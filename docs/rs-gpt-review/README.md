# 연연 1~3장 모의 원고 직접 감수

두 편 모두 가상 입력으로 계산한 명식을 바탕으로 로컬에서 편집했습니다. 윤하·도현은 기존 모의 원고 개정본이고, 해원·지안은 로컬 원고를 다른 논지와 장면으로 편집한 사례입니다. 실제 OpenAI API 생성 원고는 없습니다. 비교 기준 커밋은 `11327f87d19aac9ecdde87dce9cd7dcca334766b`입니다.

| 사례 | 비교할 지점 | 전체 원고 | 계산·작품과 문단별 근거 |
| --- | --- | --- | --- |
| 윤하·도현 | 일지끼리 직접 합·충이 없고, 다른 위치에서 교차 조합이 생깁니다. 한 사람의 출생시간이 미상입니다. 춘향전이 선정됐습니다. | [1~3장](01-yunha-dohyeon.md) | [JSON](01-yunha-dohyeon.json) |
| 해원·지안 | 두 일지는 직접 충을 이루고, 별도의 위치에서는 합과 형이 함께 보입니다. 두 사람 모두 출생시간 미상입니다. 백사전이 선정됐습니다. | [1~3장](02-haewon-jian.md) | [JSON](02-haewon-jian.json) |

Markdown과 JSON에는 같은 전체 원고가 있습니다. 각 Markdown 문단의 근거 ID를 JSON의 `payload.facts`에서 찾아 소유자·기둥·방향을 확인할 수 있습니다. `payload.charts`에는 확정 명식과 미확정 위치가, `payload.couple`에는 선정 작품과 등록 사건이 있습니다. 작품 사건은 매칭 데이터의 편집 요약입니다. 각 원고 하단에는 해당 작품에 연결된 기존 일러스트 파일이 있습니다.

## 개발자2에 첨부해 직접 감수받기

두 Markdown과 두 JSON, [적용 규칙](PROMPTS.md)을 첨부한 뒤 다음과 같이 요청하세요.

> 두 편의 1~3장 원문을 전부 읽고 비교 감수해 줘. 내 SS1~SS3가 이 대화에서 확인되면 같은 장별 기준으로 비교해 줘. 먼저 각 편에서 독자가 돈을 내고 읽을 만한 대목과 설득력이 약한 대목을 각각 인용해 줘. 명리 주장은 문단 번호와 JSON 근거 ID로 검증하고, 계산·해석·가상 사례를 나누어 판단해 줘. 이어 두 편의 구성과 한국어 리듬, 반복, 해설의 개인화, 유명 커플 비유가 작품의 구체적 사건에 기대는지를 비교해 줘. 고칠 부분은 원문과 수정 예시를 함께 보여 주고 어떤 변경을 집필 또는 편집 프롬프트에 넣을지 제안해 줘. 자료는 로컬 모의 원고이므로 실제 GPT API 품질과 응답 시간은 이번 평가에서 판단을 보류해 줘.

## 승인 후 유료 시험안

승인 범위는 가상 사례 두 편, 편당 집필 1회와 편집 1회, 총 4회입니다. 현재 코드의 보수적 예약액은 호출당 USD 0.523, 두 편 합계 USD 2.092입니다. 실제 청구와 별개로 시험 전에 프로젝트가 사용할 수 있는 현행 Responses API 모델 ID와 요율을 확인하고 그 요율로 예약액을 다시 계산합니다. 코드의 `sol-62`는 실험 프로필이므로 접근 가능한 API 모델인지 별도로 확인합니다. 원장 잔여 횟수와 예산이 승인 범위를 충족해야 합니다.

승인 후 운영과 격리된 로컬 환경에서 공개 호출은 비활성 상태로 두고, 같은 두 입력을 한 편씩 실행합니다. 집필과 편집의 원고, 최종 검증 결과, 실제 응답 모델, 토큰 수, 비용과 총 소요 시간을 기록합니다. 첫 편의 출력·비용을 확인한 뒤 두 번째 편을 진행합니다. 실패 시 원인과 원장 예약 상태를 확인하고 추가 호출은 별도로 승인받습니다. 종료 후 시험 환경의 실호출도 비활성 상태로 되돌립니다.
