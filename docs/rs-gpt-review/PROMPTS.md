# 적용된 집필·편집 규칙

## 실제 요청 구성

[집필 코드](../../rs_gpt.py)의 `INSTRUCTIONS + PERSONALIZED_INSTRUCTIONS`에 [v3 핵심 규칙](../../rs_gpt_rules_v3.md)이 포함됩니다. 요청에는 두 이름, 확정 명식, 문단에 사용할 수 있는 근거 ID와 서버가 선정한 작품의 등록 사건이 함께 들어갑니다. 문체 참고는 [RS v2 승인 원고](../../rs_gpt_approved_v2.md)의 일러스트 절 앞까지와 [RS v3 편집 예시](../RS_GPT_V3_EDITORIAL.md)의 작품 선정 절 앞까지입니다. 두 번째 요청은 여기에 초안과 자동 검사 진단을 입력으로 더하고 `EDITOR_INSTRUCTIONS`를 적용합니다. 예시 인물의 관계나 사건, 문장을 새 입력에 옮기지 않는 규칙을 둡니다.

## 장별 기준과 이번 반영

| 단계 | 적용 규칙 |
| --- | --- |
| 1장 | 4~6문단, 550자 이상. 사람마다 근거가 붙은 문단 2개 이상. 월간과 월지 본기를 구분하고 미확정 범위를 알립니다. |
| 2장 | 6~9문단, 950자 이상이며 가장 긴 장. 양방향 일간 십성, 자기 기준과 상대 기준의 배우자궁, 일지 직접 관계를 구별합니다. 명리 근거에서 서로 다른 애정 표현과 생활 갈등으로 이어집니다. |
| 3장 | 5~6문단, 650자 이상. 앞 장에서 읽은 문제를 새로운 상황의 말과 행동으로 연결합니다. 명리 개념을 재정의하거나 같은 사례를 다시 쓰지 않습니다. 작품과 커플 이름은 요청 그대로 쓰고, 2~3문장 안에 등록 사건 ID와 관계 근거를 함께 인용합니다. |
| 편집 | 초안에서 근거 위치·방향·범위, 작품 사건, 가상 장면의 단정, 비슷한 사례와 번역투를 검토한 뒤 전체 원고를 반환합니다. |
| 최종 검사 | 형태·분량·문단 근거 ID·정확히 반복한 문장·일부 명리 주장과 미확정 안내를 검사합니다. 한자로 이름 붙인 관계는 같은 문단에 해당 글자의 소유자와 위치가 있어야 합니다. 의미가 같은 사례의 반복과 작품 비유가 설득력 있는지는 직접 감수합니다. |

## 원고 감사에서 확인한 차이

- v2 승인본은 결론을 먼저 제시하고 여행 준비 사례로 행동과 합의의 차이를 보여 줍니다. v3 규칙은 명리 용어로 시작할 수 있게 하되 독자가 체감할 뜻을 바로 이어 설명하도록 합니다. 실제 집필 지시에서는 v3가 우선합니다.
- v3의 윤하·도현 참고 예시는 정인과 상관의 방향 및 일상 해석을 보여 줍니다. 합의 위치가 생략된 예시 문장을 그대로 따를 수 있어, 새 지시와 자동 검사에서 위치를 명시했습니다. 두 모의 원고에서도 소유자와 위치가 드러나도록 수정했습니다.
- 기존 윤하·도현 모의 원고는 3장에서 예약을 두 번 바꾸고 앞 장의 용어를 다시 설명했습니다. 개정본은 공동 공간, 도움을 제안하는 대화, 대화 재개, 정기 역할 분담으로 장면을 바꿨습니다. 해원·지안은 직접 일지 충에 맞춰 휴식과 대화의 시각을 중심으로 썼습니다.
- [매칭 코드](../../matcher.py)는 정상화된 여섯 관계 축의 거리로 작품을 고릅니다. GPT는 선정 결과와 사건을 받아 독자에게 닮은 이유를 설명합니다. 그림은 작품·인물과 일치하는 기존 파일을 사용합니다.
- SS1~SS3라는 이름은 연계 대화에서 확인했습니다. 저장소와 참조 대화에서 해당 명칭의 확정 원문이나 식별 가능한 링크를 찾지 못해, SS1~SS3 직접 비교는 보류했습니다. 위 RS 승인·편집 원고의 감사 결과를 SS1~SS3의 결과로 간주하지 않습니다.
