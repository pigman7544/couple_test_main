# c11 한국어·성향 키워드 편집 기록

2026-11-13. 기준 실행 `a312031`, 작업 시작 HEAD `2b4cf15`. 대상: `feat/selective-body-emphasis`와 `yeonyeon-preview-pr17`만. 운영 main 및 운영 Render 변경 금지.

## 재사용할 편집 기준

1. 주어와 행동을 바로 알 수 있게 쓴다. ‘관계의 여백’, ‘마음의 속도’처럼 뜻을 다시 풀어야 하는 명사 조합보다 ‘언제 답할지 알려 주기’, ‘다른 의견을 끝까지 듣기’처럼 구체적으로 쓴다.
2. 키워드는 비교적 지속적인 성향 두 개로 고른다. 대화·준비·배려·기다림 같은 행동이나 관계 전략을 키워드로 삼지 않는다. 책임감·독립심처럼 익숙한 명사나 ‘주관이 뚜렷함’처럼 짧고 분명한 표현을 쓴다.
3. 월주와 일간의 관계, 통근, 다른 역할과 생극 경로, 합충을 함께 읽은 기존 결론에 맞춘다. 좋은 특성만 고르거나, 원하는 키워드에 맞춰 계산·해석 분기·배역을 바꾸지 않는다. 단일 글자가 성격을 증명한다고 쓰지 않는다.
4. 사주 상징의 근거 → 원작의 구체적 행동 → 닮은 성향을 연결한다. 인물의 실제 사주라고 주장하지 않는다. 단점에는 이를 보여 주는 사건과 판단을 바꾼 행동도 함께 쓴다.
5. 인물 소제목 아래 두 키워드와 해당 근거 문단의 강조 표현은 글자까지 같게 한다. 각 키워드는 본문에서 한 번만 강조하고 문단당 강조는 최대 두 곳으로 유지한다.
6. 성향과 조언을 구분한다. ‘고집스러움이 필요하다’처럼 성향을 권하지 않는다. 성향은 설명하고, 조언에는 언제·무엇을 물어보거나 바꿀지 적는다.
7. 제목도 쉬운 말로 쓰고 반복 질문·중복 설명을 줄인다. 분량을 채우기 위한 문장은 추가하지 않는다. 무료 화면과 전체 리포트, 줄거리·가상 장면의 구분을 유지한다.

## 검증 및 배포

- `c11_integrated.extract`의 분기·노드·간선·통근·교차 근거와 배역 계산은 수정하지 않았다. `a312031` 실행을 직접 불러 A/B `chart_evidence`, 무료 응답, full_report 외 응답, 줄거리·질문·맺음말·섹션 키를 완전히 비교한다. 제목은 3장 구조를 보존하면서 편집했다.
- 다른 11종 본문은 기존 전체 응답 비교 검사로 보호한다. 공통 코드·HTML·CSS·c06 원고는 변경하지 않았다. c11에만 있는 키워드 대체 분기에도 성향 단어를 적용했다.
- 기존 테스트의 제목 문구 완전 동일 조건은 편집 대상이라 비교에서 제외했다. 섹션 키와 3장 구성 검사는 유지한다. 세 장으로 압축한 c11은 c06 대비 최소 분량 조건만 90%→80%로 조정했다. 다른 유형의 조건은 그대로다.
- 최초 제한 환경에서 HTTP 테스트 59건이 통신 권한 오류로 실행되지 않았고, 통신 가능한 환경에서 전체 재검증했다. 최종 결과와 배포 상태는 아래에 추가한다.
