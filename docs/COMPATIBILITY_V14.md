## 구현 범위

`compatibility_v14.analyze_pair(a, b)`는 기존 출생정보 딕셔너리를 받아 3장 원고를 반환한다. 명식, 근거, 미확정 범위는 기존 계산을 사용한다. `plan`에는 원국의 우선 가설과 대안, 월지와 투간·통근 근거, 관계의 상충 근거 ID, 양방향 관점, 합과 마찰이 겹치는 범위를 담는다. 원고 모듈은 이 판단을 받아 핵심 주제와 실제로 확인해 볼 질문을 구성한다. 문단의 `evidence_ids`는 원고 밖에서 검토에 쓰인다.

십성은 다섯 해석 주제를 고르는 재료다. 구체적 행동을 십성에 일대일로 배정하지 않는다. 상충 근거가 같은 글자에 겹치는 경우, 같은 기둥의 다른 층에 있는 경우, 일부만 겹치는 경우, 별개 자리에 있는 경우를 구별한다. v1.3의 계산 규칙, 우선순위와 미확정 명식 제한을 적용한다. 합화·격국·용신과 관계 길흉은 미판정이다. 서비스 경로에서 v1.4를 호출하지 않는다.

## 같은 독자로 다시 읽은 5편

평가는 합성 표본 01–05를 대상으로 한 비블라인드 편집 감수다. 명리 근거, 비약, 개별성, 자연스러움, 유료 상품 완성도를 함께 보았다.

| 표본 | 전후 독해 |
| --- | --- |
| 01 | 이전에는 월주가 불확실한데도 ‘누가 만남을 준비할지’가 양쪽의 관심으로 지정됐다. 새 원고는 첫째의 월주·시주 제한을 밝혀 두고 확인된 巳·亥와 丁·丙에서 출발한다. ‘처음부터 당연하다고 여긴 조건’은 양쪽이 실제 경험을 떠올려 검토할 수 있다. 전제 차이는 여전히 육충에 대한 상징적 독해다. 둘째의 별도 원국 주제와 두 사람의 연결이 약해 유료 원고로는 짧다. |
| 02 | 이전에는 같은 申·巳에서 합과 형이 나왔는데도 ‘일부’만 겹친다고 설명했다. 새 원고에서는 같은 글자에 두 작용이 동시에 잡힌다는 사실이 2장의 중심이고, 각자의 합의 문장을 상대의 설명 전에 적는 제안이 3장으로 이어진다. 월지 午가 두 사람에게 서로 다른 역할을 한다는 원국 비교는 본문에서 더 선명하게 풀 여지가 있다. |
| 03 | 이전에는 두 정재를 같은 비용 행동으로 제시했다. 새 원고는 첫째 丁의 월간 투간과 둘째 戊의 월간·시간 투간을 보여 준다. 甲·己가 만나는 자리와 戌·辰이 만나는 자리가 다르므로 잘 풀린 일과 엇갈린 일을 각각 떠올리게 한다. 1장의 공통 주제 반복을 더 압축하고 두 비교가 한 이야기로 이어지게 다듬을 여지가 있다. |
| 04 | 이전의 정재·정관 서술은 02와 같았다. 새 원고는 양쪽의 庚을 다른 관점으로 읽고, 두 일주의 윗글자 甲·己와 아랫글자 申·亥를 나란히 둔다. 동의한 이유와 이후에도 마음에 남은 점을 따로 묻는 질문이 구조에 맞는다. 다섯 편 중 가장 개별성이 높다. 일주와 겉글자 같은 표현은 초심자에게 다소 기술적이다. |
| 05 | 이전에는 亥卯未 삼합을 시간·역할이 맞는 경우로 바꿨다. 새 원고는 둘째 연주가 합과 상형에 함께 들어간다는 점에서 출발하고, ‘그래서 좋아’와 ‘그래도 망설여져’를 같은 일에 대해 묻는다. 이 대조는 자연스럽지만 세 글자의 삼합과 子·卯의 상형을 일상 질문으로 옮기는 과정에는 편집 가설이 남는다. |

## 재현과 한계

Python 3.11과 저장소 의존성을 사용한다.

```sh
python -m unittest discover
python evaluate_compatibility_v14.py docs
```

24쌍 모두 명식·확정 범위·교차 작용·근거 사전·해석 가정이 동일했다. 상충 근거가 있는 23쌍을 두 버전 모두 다뤘다. 저녁 약속이 나오는 원고는 20편에서 0편, 본문 안의 중복 문장 검출 수는 13건에서 0건으로 줄었다. 근거 ID 없는 문단과 존재하지 않는 ID는 두 버전 모두 0건이다.

Python 회귀 테스트 46개가 통과했다. 기존 미리보기와 테스트 언락 HTTP 경로, 카드 응답, 보호 파일 검증을 포함한다.
별도 JavaScript 레이아웃 테스트는 기준 브랜치에서도 실패한다. 기존 백소정·허선 제목은 ‘어떤 이야기를 남겼을까?’이고 테스트는 ‘어떤 사랑을 했을까?’를 기대한다.

v1.4의 마무리 문단은 24편 중 12종이다. v1.3은 20종이었다. 같은 근거 구조에 비슷한 질문을 주는 방식이므로 문구의 다양성은 오히려 줄었다. 총 본문은 30,242자에서 15,378자로 줄었다. 원고가 명료해진 만큼 유료 상품으로서 서사의 분량과 깊이는 더 검증할 필요가 있다. 표본은 합성 입력이고 감수자는 한 명이다. 실사용자·외부 명리 검토와 판매 적합성은 확인하지 않았다.
