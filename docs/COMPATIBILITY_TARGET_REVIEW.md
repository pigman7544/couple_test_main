[독자용 기준 원고 5편](COMPATIBILITY_TARGET_MANUSCRIPTS.md) · [v1.4 생성 샘플](COMPATIBILITY_V14_SAMPLES.md) · [선행 문장별 감수](COMPATIBILITY_V14_BASELINE.md) · [v1.4 검토](COMPATIBILITY_V14.md)

기준은 GitHub v1.4 브랜치의 `c767a7f834ba910dbe53a8b9e2d6fa53e0bd4c64`다. 요청의 BASELINE은 이 브랜치의 `COMPATIBILITY_V14_BASELINE.md`로 해석했다. 이 문서는 해당 파일의 v1.3 감수와 별도로 v1.4 실제 원고를 직접 대조한다. 동일 합성 입력으로 비교할 수 있고 다섯 가지 관계 근거 배치를 모두 다루는 01–05를 채택했다. 출생 입력은 [비교 데이터의 pairs 1–5](COMPATIBILITY_V14_COMPARISON.json)에 있다. 목표 원고에서 ‘첫째’는 a, ‘둘째’는 b다.

## 계산과 해석의 경계

- 명식은 기준 샘플의 연·월·일·시 순서다. 저장소의 양력 절입 계산은 한국 UTC+9, 입춘 연 경계와 태양 황경 30도 단위 월 경계를 따르고, 일주는 민간 날짜를 사용한다. 23시 일주 교체나 출생지 보정은 적용 범위 밖이다. 시간 미입력은 시주를 비우고, 같은 날 양끝에서 연·월주가 달라지면 해당 주를 미확정 처리한다.
- 자평식 월지 본기와 v1.2 지장간 배열을 채택한다. 절입 후 경과 일수에 따른 사령은 적용하지 않는다. 일간을 제외한 동일 천간을 투간으로 확인하고, 통근에서는 일간과 같은 글자와 음양이 다른 동오행 후보를 구별한다. 월령·중복·위치에 붙는 가중치는 편집용이다. 월지 본기와 일지 투간이 경합하면 선택 이유를 남긴다.
- 십성은 일간 기준 생극과 음양으로 계산한다. 교차 십성의 화살표는 ‘누가 상대 글자를 읽는가’를 뜻한다. 지지 작용의 관점 비교는 해당 지지 본기를 읽은 보조 근거다. 같은 글자의 천간·지장간과 서로 다른 소유자의 반복 위치는 각각 기록한다.
- 교차 합충형해는 v1.1 조합표를 따른다. 巳申 두 글자로 상형을 기록하는 선택은 학파 가정이다. 02의 설명은 삼형 완성을 전제로 삼지 않는다. 삼합은 세 글자가 모두 있는 자리를 요구하고, 원국 내부와 교차 조합을 각각 본다. 합화·조후·격국·용신·길흉 판정은 이번 원고의 범위 밖이다.
- 아래의 명식·위치·십성·조합은 채택 규칙 내 확인 항목이다. 말투, 호감, 행동, 장면, 실천은 이를 읽고 세운 편집 가설이다. 기둥에 특정 날짜의 사건이나 생활 영역을 자동 배정할 근거는 없다. 질문에 맞는 경험이 떠오르지 않으면 의도한 장면을 일반화하지 않는다.

## 문단별 근거

각 장의 첫째·둘째 본문 문단을 각각 `1.1`, `1.2`와 같이 표기한다. 원고 도입의 공통 고지는 해석 범위에 관한 안내다. 아래 ID는 해당 표본의 v1.4 근거 사전을 기준으로 한다. 3장 문단의 ID는 실천이 응답하는 가설의 출처다.

### 01 · 확인된 구조로 읽는 각자의 시간

a `壬申 / — / 丁巳 / —`, b `辛酉 / 辛卯 / 丙戌 / 己亥`. a의 월주와 시주가 미확정이다. 巳 속 丙은 丁과 같은 화이지만 음양이 다르다. b의 戌 속 丁도 丙과 다른 음양의 보조 근거다.

| 문단 | 근거 ID와 위치 | 계산에서 원고까지 |
| --- | --- | --- |
| 1.1 | `a.coverage`, `a.day.stem`, `a.day.hidden.丙`, `a.day.hidden.庚` | 일지 巳 본기 丙 겁재와 중기 庚 정재. 자율성과 감당 가능한 몫을 나란히 묻는다. |
| 1.2 | `b.day.stem`, `b.month.hidden.乙`, `b.day.hidden.辛`, `b.year.stem`, `b.month.stem` | 卯 본기 乙 정인과 戌 속 辛 정재. 辛이 연·월간에도 있어 맥락 이해와 구체적 약속을 함께 읽었다. |
| 2.1 | `pair.a.reads.b`, `pair.b.reads.a` | 丁→丙·丙→丁 둘 다 겁재. 서로 자기 판단을 가진 점을 좋게 볼 가능성은 십성 가설이다. |
| 2.2 | `pair.육충.a.day.b.hour`, `a.day.hidden.丙`, `b.hour.hidden.壬`, `pair.a.reads.b`, `pair.b.reads.a` | a 일지 巳와 b 시지 亥의 육충. 동등한 선택권을 기대하며 전환의 전제는 다를 수 있다는 가설. 어느 쪽이 먼저 말할지는 배정하지 않았다. |
| 3.1 | `pair.육충.a.day.b.hour`, `b.month.hidden.乙` | 각자가 들은 범위와 전후 사정을 대조한다. |
| 3.2 | `pair.육충.a.day.b.hour`, `pair.a.reads.b`, `pair.b.reads.a` | 독립성을 유지하며 연결 신호를 바꿔 보고, 부담도 함께 확인한다. |

선택된 축은 육충과 양방향 십성이다. 끌림의 근거를 별도의 교차 합으로 채우지 않았다. 미확정 자리에 새 작용이 들어올 가능성은 열린다.

### 02 · 같은 지지에서 합과 형

a `甲寅 / 庚午 / 丙申 / 丙申`, b `癸亥 / 戊午 / 辛巳 / 甲午`. a는 申 속 庚과 午 속 丁이 편집 점수에서 동점이다. 庚의 월간 노출과 일·시지 반복을 본문 주축으로 삼고, 丁은 남겨 같은 午를 b와 견준다. a 연지 寅의 丙은 직접 뿌리다. b 일지 巳 속 庚은 辛과 음양이 다른 보조 근거다.

| 문단 | 근거 ID와 위치 | 계산에서 원고까지 |
| --- | --- | --- |
| 1.1 | `a.day.stem`, `a.day.hidden.庚`, `a.hour.hidden.庚`, `a.month.stem`, `a.month.hidden.丁` | 일·시지 申의 庚 편재가 월간에 투간. 옵션을 열어 보는 가설에 午의 丁 겁재에서 읽는 참여 여지를 붙였다. |
| 1.2 | `a.month.hidden.丁`, `b.day.stem`, `b.month.hidden.丁`, `b.day.hidden.戊`, `b.month.stem` | 같은 午 본기 丁이 a에겐 겁재, b에겐 편관. b의 巳 속 戊 정인은 월간에도 있어 기준을 확인할 때 설명의 역할을 더했다. |
| 2.1 | `pair.a.reads.b`, `pair.b.reads.a`, `a.day.hidden.庚`, `b.month.hidden.丁`, `pair.육합.a.day.b.day` | 丙→辛 정재, 辛→丙 정관. 상대에게서 현실적 약속과 믿고 따를 기준을 읽는 접점. 원국의 편재·편관과 방향별 정재·정관은 서로 다른 근거다. |
| 2.2 | `pair.육합.a.day.b.day`, `pair.상형.a.day.b.day`, `a.day.hidden.庚`, `b.day.hidden.丙` | a 일지 申과 b 일지 巳에 둘 다 성립. 申 본기 庚은 a 편재·b 겁재, 巳 본기 丙은 a 비견·b 정관. 함께 굴릴 방법이 각자의 선택권과 책임 범위에 걸릴 수 있다. |
| 3.1 | `pair.육합.a.day.b.day`, `pair.상형.a.day.b.day` | 같은 합의에 대해 서로 기억하는 범위를 독립적으로 기록한다. |
| 3.2 | `pair.육합.a.day.b.day`, `pair.상형.a.day.b.day`, `b.month.hidden.丁` | 시험 단계와 책임이 생기는 확정 시점을 나누고, 어느 쪽에서 부담이 생겼는지 확인한다. |

a 시지 申과 b 일지 巳에도 같은 조합이 성립한다. 본문에서 고른 두 위치는 각각 a 일지와 b 일지다. 반복을 실제 사건 횟수로 읽지 않았다.

### 03 · 별개 자리에서 합과 충

a `甲寅 / 丁丑 / 壬戌 / 甲辰`, b `己未 / 戊辰 / 乙巳 / 戊寅`. a는 丑 본기 己와 戌 속 丁이 편집 점수에서 동점이고, 丁이 월간에 보여 두 원국을 비교하는 실마리로 택했다. a의 丑 속 癸는 壬과 음양이 다른 보조 근거, b 연지 未 속 乙은 직접 뿌리다.

| 문단 | 근거 ID와 위치 | 계산에서 원고까지 |
| --- | --- | --- |
| 1.1 | `a.day.stem`, `a.day.hidden.丁`, `a.month.stem`, `a.month.hidden.己` | 戌 속 丁 정재가 월간에 나타나며 丑 본기 己 정관을 함께 본다. 맡을 수 있는 구체적 몫과 그 지속성을 묻는다. |
| 1.2 | `b.day.stem`, `b.month.hidden.戊`, `b.month.stem`, `b.hour.stem`, `b.day.hidden.丙` | 辰 본기 戊 정재의 두 투간 자리와 巳 본기 丙 상관. 운영 조건과 관행을 고쳐 볼 여지를 함께 읽었다. |
| 2.1 | `pair.천간합.a.hour.b.year`, `a.hour.stem`, `b.year.stem`, `pair.a.reads.b`, `pair.b.reads.a` | a 시간 甲·b 연간 己 천간합. 壬→乙 상관, 乙→壬 정인. 관찰된 결론을 뜻하지 않는 접점과 표현·수용 가설이다. |
| 2.2 | `pair.천간합.a.hour.b.year`, `pair.육충.a.day.b.month`, `a.day.hidden.戊`, `b.month.hidden.戊` | a 일지 戌·b 월지 辰 육충은 합의 위치와 분리된다. 두 지지의 본기 戊는 壬에겐 편관, 乙에겐 정재. 운영의 같은 조건이 부담과 관리할 자원으로 달리 해석되는 장면을 골랐다. |
| 3.1 | `pair.천간합.a.hour.b.year`, `pair.육충.a.day.b.month` | 공통 목적과 마찰이 생기는 운영 항목을 따로 기록한다. |
| 3.2 | `pair.육충.a.day.b.month`, `a.day.hidden.丁`, `b.month.hidden.戊` | 운영 하나만 조정한 뒤 다음 회차에도 지속 가능한지와 수고의 이동을 확인한다. |

a 연간 甲과 b 연간 己도 합 후보다. 본문의 시간–연간 조합은 v1.4 선택이며 다른 합 후보를 제거하지 않는다.

### 04 · 같은 일주의 다른 층

a `丁亥 / 庚戌 / 甲申 / 己巳`, b `癸丑 / 庚申 / 己亥 / —`. b의 시주가 미확정이다. a 연지 亥 속 甲과 b 연지 丑 속 己는 각자의 직접 뿌리다. a 월지 본기 戊보다 일지 申의 庚과 월간 庚 연결을 선택했다.

| 문단 | 근거 ID와 위치 | 계산에서 원고까지 |

### 05 · 삼합과 형이 한 자리만 공유

a `丁亥 / 壬子 / 乙未 / —`, b `丁卯 / 辛亥 / 辛巳 / 乙未`. a의 시주 미확정. a 일지 未의 乙은 직접 뿌리, b 일지 巳의 庚은 음양이 다른 동오행 보조 근거다.

| 문단 | 근거 ID와 위치 | 계산에서 원고까지 |
| --- | --- | --- |
| 1.1 | `a.coverage`, `a.day.stem`, `a.month.hidden.癸`, `a.month.stem`, `a.day.hidden.丁`, `a.year.stem` | 子 본기 癸 편인과 월간 壬 정인은 별개 글자다. 未 속 丁 식신은 연간에도 있어 생각을 안에서 소화하는 방식과 작게 만들어 보는 방식을 견준다. |
| 1.2 | `b.day.stem`, `b.month.hidden.壬`, `b.day.hidden.丙` | 亥 본기 壬 상관과 巳 본기 丙 정관. 변경하고 싶은 방법과 지키고 싶은 합의가 공존할 수 있다는 가설이다. |
| 2.1 | `pair.삼합.a.day.b.year.b.month`, `a.day.hidden.己`, `b.year.hidden.乙`, `b.month.hidden.壬`, `pair.a.reads.b`, `pair.b.reads.a` | a 일지 未·b 연지 卯·b 월지 亥 삼합. 乙→辛 편관, 辛→乙 편재. 압력도 계기도 될 수 있는 선명한 제안과 선택지가 넓어지는 관점이 만난다. 장면의 세 요소는 비유이며 글자별 대응은 가정하지 않는다. |
| 2.2 | `pair.삼합.a.day.b.year.b.month`, `pair.상형.a.month.b.year`, `b.year.hidden.乙`, `a.month.hidden.癸` | 형은 a 월지 子·b 연지 卯이며 b 연지만 공유한다. 卯 속 乙은 a 비견·b 편재, 子 속 癸는 a 편인·b 식신. 함께 만들자는 제안 안에서도 바깥으로 알리는 범위에 망설임이 생기는지 시험할 수 있다. |
| 3.1 | `pair.삼합.a.day.b.year.b.month`, `pair.상형.a.month.b.year` | 같은 활동의 필요 조건과 밖으로 넓힐 때의 조건을 각각 묻는다. |
| 3.2 | `pair.삼합.a.day.b.year.b.month`, `pair.상형.a.month.b.year`, `a.month.hidden.癸` | 작은 실행 뒤 재실행 의사와 공유 의사를 각자 다시 확인한다. |

이 표는 v1.4가 선택한 교차 삼합 한 조합을 추적한다. a 연지 亥·a 일지 未·b 연지 卯 등 다른 교차 조합도 있고, b 원국 자체에도 亥·卯·未가 있다. 어느 한 사람이 상대에게 없는 성질을 채워 준다고 해석하지 않았다.

## 품질 루브릭과 자체 감수

각 항목은 0–2점이다. 0은 누락이나 명백한 비약, 1은 부분 충족, 2는 아래 조건 충족이다. 편집 회람 기준은 12점 중 10점 이상, 계산·추적과 불확실성 항목 각각 2점이다. 유료 출시 판정에는 별도 명리 감수와 고객 독해가 필요하다.

| 항목 | 2점 기준 |
| --- | --- |
| 계산·추적 | 모든 문단이 실제 ID로 해소된다. 채택 학파와 미확정 범위가 명시되고, 위치·음양·관점·겹침을 재검산할 수 있다. |
| 각자의 관계 방식 | 양쪽이 독립적으로 읽히고, 같은 십성이거나 같은 글자일 때도 명식 내 배치와 작용을 비교한다. |
| 관계 서사 | 한 장면에서 끌림과 마찰이 어떻게 공존하는지 설명한다. 합·충·형·해와 교차 십성의 자리를 바꾸면 장면의 논리도 달라진다. |
| 불확실성 | 실제 성격·사건·역할·미래를 귀속하지 않는다. 선택한 장면이 빗나갔을 때 독자가 자기 경험을 답할 여지가 있다. |
| 한국어·깊이 | 세 장이 읽기 쉬운 한국어로 이어지고, 각 장이 새 역할을 한다. 의미가 같은 근거 풀이가 다른 문장으로 되풀이되지 않는다. |
| 질문·실천 | 본문 가설을 가르는 질문이 있다. 해볼 행동, 부담이 생기는 지점, 다음에 무엇을 볼지가 구체적이다. |

## v1.5에 일반화할 규칙

1. **사실을 먼저 고정한다.** 명식 후보, 확정 범위, 지장간, 투간, 통근 종류, 교차 작용의 소유자·기둥·층·글자, 방향별 십성을 보존한다. 슬롯에는 실제 기둥 위치를 쓴다. 미확정 위치에는 근거를 생성하지 않고, 대체 시각에서 주요 근거가 바뀌는 경우 확정 부분만 출력한다. 검수 때 시간 미입력과 절입 경계 입력을 따로 확인한다.
2. **월지와 투간이 경합하면 양쪽을 기록한다.** 원국별 주 가설과 대안에 각각 근거를 붙인다. 02의 같은 午와 03의 같은 정재처럼, 동일한 분류라도 위치·노출·보조 근거가 다르면 문단을 비교해 차이를 설명한다. 십성별 행동 사전을 그대로 호출하지 않는다. 양쪽 인물을 교환하면 소유자와 관점이 따라 바뀌는지 확인한다.
3. **상충 근거의 위치가 서사를 결정하게 한다.** 같은 지지의 두 작용은 하나의 선택에서 통함과 부담을 함께 묻는다. 기둥만 같고 층이 다르면 동의와 전달 경험을 나눠 본다. 일부 공유면 겹친 참여·조건 하나를 좁혀 묻고, 별개면 잘 맞는 항목에서 마찰 항목까지 합의됐다고 확대하지 않는다. 한쪽 작용만 채택되면 교차 십성이나 원국을 통해 가능한 접점을 제시하고 근거 종류를 구별한다. 같은 글자의 중복이 서로 다른 위치에 있으면 검수 데이터에 남기되, 문단이나 사건을 중복 생성하지 않는다.
4. **장면은 검증 가능한 가설로 선택한다.** 장면에 십성이나 기둥을 고정 대응시키기 전에 두 사람이 같은 말을 달리 이해할 수 있는 이유를 한 문장으로 요약한다. 본문 안에서 그 차이를 말·선택·선후 관계로 보여 준다. 다른 쌍의 원고에 장면과 마무리를 통째로 옮겨도 설명이 바뀌지 않으면 다시 쓴다.
5. **질문은 가설을 구분하고 실행은 작게 만든다.** 독자의 답이 다르면 할 일도 달라져야 한다. 01은 다시 연결될 시점, 02는 시험에서 확정으로 넘어가는 순간, 03은 공통 목적과 운영 절차, 04는 결론의 동의와 발화 참여, 05는 실행과 외부 공유를 분리한다. 각 행동에는 시점과 되돌아볼 지표를 둔다.
6. **근거와 문장의 연결을 회귀 검증한다.** 문단마다 원국 사실·관계 가설·독자 행동을 트레이스에서 표시한다. ID 존재 여부와 함께 방향 반전, 근거 제거, 관계 위치 변경, 장면 교환을 검토한다. 알려진 입력 5쌍의 결과에만 맞는 규칙을 피하도록 새 합성 사례에서 블라인드 편집 검토를 두고, 성별·삶의 사건·관계 결과를 추론하는 문구는 출시 전에 차단한다.

## 검증 범위와 한계

- 로컬 v1.4 샘플·선행 감수 파일의 Git blob SHA를 GitHub 기준 커밋의 파일과 대조했다. 명식 스냅샷을 고정 입력으로 공급해 저장소의 원국·교차 근거·v1.4 서술 선택을 재실행했고, v1.4 본문 5편이 샘플과 일치했다.
- 이번 검증은 확정된 명식 이후의 지장간·십성·교차 작용·위치에 한정한다. 로컬 Python 3.12에는 Swiss Ephemeris 호환 모듈이 없고 확보된 바이너리는 Python 3.11용이어서 출생 입력부터의 절입 재계산과 전체 Python HTTP·회귀 테스트는 수행하지 못했다. v1.4 기록의 46개 통과는 이번 재실행 수치로 사용하지 않는다.
- 원고 15장·30문단과 표의 30개 연결 행, 문단별 ID 및 위치·관점, 상대 링크를 확인했다. 기존 JavaScript 레이아웃 테스트는 기준과 같은 제목 불일치로 실패했다. 실제 제목 ‘어떤 이야기를 남겼을까?’와 기대값 ‘어떤 사랑을 했을까?’의 차이다.
- 검토 범위는 문서 두 편이다. 기존 RS·IL1·미리보기1·UI·서비스 경로는 PR 변경 목록 밖이다. 실사용자 읽기, 유료 구매자 평가, 독립 명리 감수, 화면에 배치했을 때의 분량 검증은 아직 수행하지 않았다.
