# RS GPT 원고 품질 평가

기준은 Draft PR #39의 `a307be5`와 2026-11-26에 저장한 [실생성 원고·실패 진단](rs-gpt-live-20261126/README.md), [당시 프롬프트](rs-gpt-live-20261126/PROMPTS.md)다. 새 API 호출 없이 저장 원고를 재검사했다.

## 발견 및 변경

| 평가 | 윤하·도현 실생성본 | 해원·지안 실생성본 | 이번 변경 |
| --- | --- | --- | --- |
| 구성 | 소제목 2 / 7 / 5개. 2장에서 합·충·형·해가 각각 제목을 차지한다. | 2 / 8 / 5개. 읽는 사람별 십성과 배우자성이 별도 소주제로 이어진다. | 장마다 2~3개, 28자 이하. 2장의 첫 소주제에서 우선 근거를 인용하고, 주요 관점을 소주제 안에 묶는다. |
| 2장의 관계 | 두 일지 사이에 직접 합·충이 없다. 월지와 일지 사이의 충은 이미 들인 시간이나 약속을 어떻게 볼지 설명하는 데 유용하다. | 일지끼리 사해충이 있다. 별개 위치의 합·형이 있어도 2장의 중심은 친밀함 안에서 서로의 기준과 선택권을 어떻게 받아들이는가다. | 계산 자료에서 직접 일지 관계를 먼저 전달한다. 해당 관계가 없을 때는 양방향 일간을 출발 근거로 제공한다. 일지가 관여하는 교차 관계도 후보로 제공한다. |
| 근거와 검증 | 실제 실패는 도현의 월지 戌 속 丁을 식신으로 풀이한 대목이다. 월지의 대표 지장간 이외에도 글자를 명시하면 정확한 근거를 확인할 수 있다. | 실제 실패는 해원의 월지 卯 본기 乙을 식신으로 풀이한 대목이다. ‘해원님에게’는 이 문장에서 자기 원국을 읽는 기준이다. | 두 실패 문장을 회귀에 고정했다. 틀린 십성·글자는 거절한다. ‘본기인’ 표현, 일간을 명시한 교차 해석, 일반 동사 ‘해 보고’의 범위 판정도 보완했다. |
| 반복과 편집 | 제안과 기존 결정 구분, 대화에 돌아올 시간, 역할 재조정이 나온다. | 유사한 조언이 반복돼 2장에서 드러난 사해충과 선택권의 차이가 3장에서 흐려진다. | 요청에서 참고 원고 전문을 빼고 편집 기준을 직접 적었다. 기존 초안·편집 두 단계에서 같은 우선 근거를 제공한다. 편집 시 인물 이름을 바꿔도 통하는 진술, 겹치는 장면과 요약을 다시 본다. |

‘개발자2’에서 검토한 교정본의 기준은 관계마다 다른 중심 질문이다. 윤하·도현 사례에서 눈여겨볼 부분은 제안을 실행 가능한 합의로 바꾸는 협력과 기존 약속에 이미 들인 수고다. 해원·지안 사례에서는 두 사람 모두 일지 본기가 정재인 공통점과, 상대의 일간과 본기를 읽는 방향별 차이가 같은 관계에서 어떻게 드러나는지가 중요하다. 이 논지와 장면은 두 사례의 평가 근거로 쓴다.

## 실행

저장소 루트에서 의존성을 설치한 Python 3.11로 실행한다. HTTP 회귀는 루프백 주소를 사용하고 Responses API 전송은 모의 처리한다. 실호출을 끄고 API 키를 비워 실행할 수 있다.

```sh
python -m unittest -v test_v67 test_compatibility_v14 test_rs_preview test_rs_gpt test_rs_gpt_quality
python test_rs_gpt_quality.py
```

새 평가에는 다음 사례를 고정했다. A는 1992-03-18 출생 시각 미상이다. B는 같은 해 3월 아래 날짜·시각을 사용한다. 각 사례에서 A/B 순서도 뒤집는다.

| B | 출생 시각 | 일지 직접 관계 | 일간 오행 |
| --- | --- | --- | --- |
| 19일 | 10시 | 없음 | 상이 |
| 28일 | 미상 | 없음 | 동일 |
| 21일 | 10시 | 육합·상형 | 상이 |
| 24일 | 미상 | 육충 | 상이 |
| 27일 | 10시 | 육해·상형 | 동일 |

각 입력에서 우선 근거와 보조 후보의 위치를 검사한다. 두 실생성본은 소제목 수와 문단별 명리 검사 결과를 재생한다. 구조 검사는 저장된 테스트 원고의 소제목 과다와 핵심 근거가 늦게 나오는 경우를 거절하는지 확인한다. 기존 HTTP 회귀에는 40개 생년월일 조합의 로컬 원고, 미리보기, 모의 전체 원고, 카드 관련 검사가 포함된다.

2026-11-27 기준 전체 41개 테스트 통과. 대표 5쌍을 양방향으로 검사해 10개 입력 순서를 확인했다.

## 사람 감수 기준

새 원고를 평가할 때 사용한다. 각 항목에서 해당 문단과 근거 ID를 기록하고 0점(누락 또는 오류), 1점(충족하나 일반적), 2점(입력에 구체적이고 읽기 자연스러움)으로 채점한다. 명리 주장 오류는 합계와 별개로 수정 대상으로 기록한다.

1. **구조와 한국어** — 한 소제목 아래 이어지는 문단이 하나의 질문을 다루는가. 전문용어를 일상 문장으로 풀고 종결과 전환을 자연스럽게 쓰는가.
2. **2장 관계 해석** — 두 사람이 각각 무엇을 하고 어떻게 받아들이는지 보이는가. 강점이 마찰로 바뀌는 조건과 관계에 보탬이 되는 조건을 같은 근거로 설명하는가.
3. **명리 정확성** — 소유자, 위치, 읽는 방향, 글자, 조합을 확인한다. 직접 일지 관계와 교차·원국 내부 관계, 확정 범위와 해석을 구분한다.
4. **차별화와 반복** — 이름을 가린 두 사례의 요약을 서로 바꿔 읽었을 때 어긋나는 지점이 있는가. 조언, 장면과 문장 틀의 반복을 비교한다.
5. **3장 연결** — 2장의 관찰에서 지금 할 수 있는 말과 행동이 이어지는가. 선정 작품의 구체적 사건은 등록된 근거에 있고 관계의 논지와 연결되는가.

## 평가 한계

- 원래 보고된 두 오류 문장은 이제 개별 검사에 통과한다. 이 재생 검사에서 윤하·도현 2장 6문단의 상형 두 건을 한 문장에 묶은 표현은 여전히 `scoped_fact_mismatch`가 나온다. 문장 안의 모든 위치를 하나의 조합으로 대조하는 검사 때문이다. 집필 지시는 조합을 한 문장에 하나씩 밝히도록 했다.
- 자동 검증은 구조와 인식 가능한 명리 표현, 근거 ID를 확인한다. 근거 ID를 달았다는 사실만으로 해석의 깊이와 실제 서술 일치까지 입증되지는 않는다. 표현이 크게 달라지면 문장 패턴 검사에 오탐과 누락이 생길 수 있다.
- 이전에 저장한 두 원고는 새 소제목 제한을 초과한다. 무료 로컬 원고와 모의 응답으로 새 프롬프트를 전달하고 편집·검증하는 경로를 확인했다. 새 프롬프트로 모델이 쓴 원고의 문체, 입력 전반의 일관성, 실제 통과율·비용·지연시간은 이번 평가에 포함되지 않는다.
