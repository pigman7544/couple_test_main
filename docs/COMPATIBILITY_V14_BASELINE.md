# v1.3 선행 원고 감수

합성 표본 01–05의 v1.3 본문을 차례대로 읽었다. 아래 번호는 각 문단 안의 문장 순서다. 명리 타당성은 기존 지장간 배열과 합충형해 규칙 안에서 검토했다. 한국어와 유료 적합성은 편집 판단이다.

| 표본·문단 | 문장별 검토 |
| --- | --- |
| 01·1장 첫째 | ① 월주 미확정 고지는 타당하나 시주도 빠졌다. ② 巳의 丙을 丁 기준 겁재로 읽는 것은 타당하며 ‘일주 사’는 일지로 고쳐야 한다. ③ 확인된 범위의 미투간은 타당하다. ④ 丙은 동오행 보조 근거이며 ‘일간에는 … 뿌리’가 어색하다. ⑤ 겁재에서 만남 준비 담당으로 비약한다. ⑥ 庚 정재는 맞지만 비용·시간이 필요하다는 결론은 과잉이다. |
| 01·1장 둘째 | ① 卯를 월지로 짚었으나 해석상 의미가 없다. ② 乙 정인은 맞다. ③ 乙의 미투간은 타당하다. ④ 戌 속 丁을 보조 근거로 보는 것은 타당하다. ⑤ 정인에서 도움 확인을 자동으로 끌어온다. ⑥ 辛 정재가 맞더라도 첫째와 같은 비용 문구로 개별성이 사라진다. |
| 01·2장 첫 문단 | ① 저녁 약속의 선정 근거가 없다. ② 丁·丙의 양방향 겁재는 맞는다. ③ 양쪽에 준비 담당이라는 동일 행동을 배정했다. ④ 누가 먼저 움직이는지는 근거에서 나오지 않는다. |
| 01·2장 둘째 문단 | ① 巳亥 충은 타당하나 일지와 상대 시지의 관계를 장면 전체로 확대한다. ② 시간과 역할이라는 대상은 주어진 적이 없다. ③ 丁 기준 겁재·丙 기준 비견은 맞는다. ④ 같은 丙의 관점 차이를 실제 두 사람의 관심사로 배정할 근거가 없다. |
| 01·3장 | ① 같은 말을 서로 묻는 문장이라 읽기 어렵다. ② 조정법은 실행 가능하지만 누구에게나 같다. ③ 다른 경험을 열어 둔 점은 좋으나 표본의 질문이 남지 않는다. |
| 02·1장 첫째 | ① 午를 소개하나 월지와 일지의 경합 설명이 없다. ② 申의 庚 편재는 맞다. ③ 월간 庚으로 투간한 사실은 중요하다. ④ 寅 속 丙은 직접 근거다. ⑤ 편재가 장소 물색을 뜻하지 않는다. ⑥ 午 속 丁 겁재는 맞으나 준비 담당을 대안으로 제시할 이유가 없다. |
| 02·1장 둘째 | ① 같은 午인데 첫째와 무엇이 다른지 바로 들리지 않는다. ② 辛 기준 丁 편관은 맞다. ③ 丁 미투간은 타당하다. ④ 巳 속 庚은 보조 근거다. ⑤ 편관을 긴급 결정 담당으로 고정했다. ⑥ 戊 정인은 맞으나 도움 확인으로 닫는다. |
| 02·2장 첫 문단 | ① 저녁 장면이 반복된다. ② 丙→辛 정재·辛→丙 정관은 타당하다. ③ 시간·비용과 규칙 확인을 양쪽의 실제 우선순위처럼 읽게 한다. |
| 02·2장 둘째 문단 | ① 申巳 상형은 채택 규칙과 일치한다. ② 합의 후 재확인이라는 순서는 추정이다. ③ 庚 편재·겁재는 타당하다. ④ 후보 찾기와 담당 배정은 지지 근거가 없다. ⑤ 같은 申巳 육합이 핵심이다. ⑥ ‘일부’는 부정확하다. 두 자리 모두 겹친다. ⑦ 다른 조건을 묻는 방향은 좋으나 무엇을 보면 두 해석을 구별하는지 없다. |
| 02·3장 | ① 앞 문단 시간·비용·규칙을 반복한다. ② 표본 01과 같은 실험으로 합·형의 공존이 사라진다. ③ 인용구를 되풀이하며 익숙한 상황만 고르게 한다. |
| 03·1장 첫째 | ① 丑을 짚으나 丁의 투간과 비교하지 않는다. ② 戌의 丁 정재는 맞다. ③ 월간 丁으로 연결된다. ④ 丑 속 癸는 보조 근거다. ⑤ 비용으로 한정할 이유가 없다. ⑥ 己 정관은 맞지만 약속 준수로 고정했다. |
| 03·1장 둘째 | ① 辰 소개는 뒤 문장에서 중복된다. ② 戊 정재는 맞다. ③ 월간·시간 두 戊는 구체적 근거다. ④ 未 속 乙은 직접 근거다. ⑤ 첫째와 같은 행동으로 서로 다른 배치가 지워진다. ⑥ 巳 속 丙 상관은 맞으나 불만 표출을 상정한다. |
| 03·2장 첫 문단 | ① 같은 저녁 장면이 세 번째다. ② 壬→乙 상관·乙→壬 정인은 맞다. ③ 불만 제기와 도움 확인을 각자의 몫으로 놓는 것은 비약이다. |
| 03·2장 둘째 문단 | ① 첫째 일지 戌과 둘째 월지 辰의 충은 타당하다. ② 서로 조건을 건다는 표현은 가정이 필요하다. ③ 戊 편관·정재는 맞지만 ‘무(戊)은’은 조사 오류다. ④ 급한 담당과 비용의 대조는 근거 대비가 아니다. ⑤ 첫째 시간 甲과 둘째 연간 己의 합은 맞다. ⑥ 별개 자리라는 설명은 중요하다. ⑦ 제안 이어받기로 바꾸면 별개 자리라는 정보가 무의미해진다. |
| 03·3장 | ① 첫 문단의 행동을 재진술한다. ② 같은 조정법이다. ③ 제안을 이어받는 것과 기존 이견이 풀리는 것을 구별하지 않는다. |
| 04·1장 첫째 | ① 월지 戌 소개에 이어 申을 택한 이유가 없다. ② 甲 기준 庚 편관은 맞다. ③ 월간 庚 투간은 주요 근거다. ④ 亥 속 甲은 직접 근거다. ⑤ 긴급 상황·담당은 임의다. ⑥ 戊 편재는 맞지만 장소 대안으로 치환한다. |
| 04·1장 둘째 | ① 월지 申은 맞으나 시주 누락 안내가 없다. ② 己 기준 庚 상관은 맞다. ③ 월간 庚 투간은 특히 첫째와 비교할 근거다. ④ 丑 속 己는 직접 근거다. ⑤ 불만을 먼저 말한다고 읽을 이유가 없다. ⑥ 亥 속 壬 정재는 맞으나 비용 예시가 재등장한다. |
| 04·2장 첫 문단 | ① 같은 저녁 장면이다. ② 甲→己 정재·己→甲 정관은 정확하다. ③ 표본 02와 동일 문장이라 서로 다른 교차 구조를 가린다. |
| 04·2장 둘째 문단 | ① 일지 申亥 육해는 타당하다. ② 선의와 부담을 사주로 추측한다. ③ 양쪽에서 같은 庚이 다르게 읽히는 관찰은 유효하다. ④ 배정한 행동은 그 관찰을 입증하지 못한다. ⑤ 일간 甲己합은 맞다. ⑥ 두 사람의 일주라는 위치는 모두 겹치되 층은 다르다. ⑦ 제안 이어받기보다 겉으로 맞는 판단과 실제 수용을 구별할 필요가 있다. |
| 04·3장 | ① 표본 02와 같은 출발이다. ② 육해의 미묘한 차이를 동일한 규칙 조정으로 처리한다. ③ 제안 이어받기를 반복해 끝낸다. |
| 05·1장 첫째 | ① 子 월지는 맞으나 시주 미확정은 빠졌다. ② 癸 편인은 맞다. ③ 癸 미투간은 맞지만 월간 壬과의 동오행 구별이 독자에게 없다. ④ 未 속 乙은 직접 근거다. ⑤ 숙고 시간이 필요하다는 배정은 임의다. ⑥ 丁 식신은 맞지만 작은 배려로 정해 버린다. |
| 05·1장 둘째 | ① 亥 소개가 뒤 문장과 겹친다. ② 壬 상관은 맞다. ③ 壬 미투간은 타당하다. ④ 巳 속 庚은 보조 근거다. ⑤ 불편을 말한다고 읽는 배정은 임의다. ⑥ 丙 정관은 맞으나 행동으로 곧장 치환한다. |
| 05·2장 첫 문단 | ① 또 저녁 약속이다. ② 乙→辛 편관·辛→乙 편재는 맞다. ③ 관계의 구체성을 급한 담당과 장소 찾기로 대신했다. |
| 05·2장 둘째 문단 | ① 두 명식에 걸친 亥卯未 삼합은 규칙에 맞는다. ② 시간·역할이 함께 맞아야 한다는 주장은 과도하다. ③ 己 편재·편인은 맞지만 ‘기(己)은’은 조사 오류다. ④ 첫째의 후보 탐색과 둘째의 숙고는 임의다. ⑤ 子卯 상형은 타당하다. ⑥ 실제로 둘째 연지 卯가 겹친다. ⑦ 합의 재확인은 형에 대한 여러 가설 가운데 하나일 뿐이다. |
| 05·3장 | ① 같은 인용 방식으로 이미 한 말을 반복한다. ② 합의와 부담을 한 번씩 점검하는 제안은 실행 가능하지만 삼합의 구체성을 쓰지 않는다. ③ 형의 작용을 확인하기보다 익숙한 장면을 찾는다. |

공통 고지 두 문장은 상징의 범위와 예측 한계를 적절히 밝힌다. 01은 제한된 범위의 짧은 원고가 적합하다. 02는 申巳의 이중 관계를 중심으로 다시 구성할 가치가 높다. 03은 두 정재의 근거 차이와 별개 자리를 살리면 판매 원고에 가까워진다. 04는 같은 庚과 두 층의 동시 작용이 가장 좋은 재료다. 05는 삼합과 상형이 卯를 공유한다는 사실을 질문에 반영해야 한다. 다섯 편 모두 현재 유료 상품에 쓰기에는 장면·행동·마무리가 지나치게 반복된다.
