## 보존 대상

- 두 사람의 이름을 입력하는 흐름
- 1장 명식 표와 성격 해석
- 2장 궁합 해석과 짧은 문학 코너
- 3장 행동과 소통 조언
- 카드, 미리보기, 테스트 언락 기능
- 체험판의 기존 디자인
